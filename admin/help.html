管理画面のヘルプ

品ぞろえ（管理）の画面で、何が見られて、数字をどう読めばよいかをまとめました。本物の数字を見るには管理用の合言葉が必要です。見え方だけなら、合言葉なしのデモで確かめられます。

🧪 デモを見る

サンプルの数字で「📈 採用率」「🤝 投稿者」のタブを表示します。サーバーには何も送りません。

デモを開く
目次
  1. 📈 採用率（どの料理が献立に選ばれているか）
  2. 📥 集める（新着の料理を集める）
  3. 休んでいる料理と、毎朝の健康診断
  4. 🤝 投稿者
  5. 📚 レシピ一覧・🍲 親の料理名

1. 📈 採用率

集めた料理が、利用者の献立にどれくらい選ばれているかを料理ごとに見る表です。この月と前の月（日本時間の暦）を数えます。

列意味
候補に出た献立の候補として、利用者の画面に出た回数（同じ端末・同じ料理は1日1回）
献立に入ったその料理が献立に入った回数
作った利用者が「作った」を押した回数
採用率献立に入った ÷ 候補に出た。候補に出た回数が少ないうちは「—」
残す✓＝新着から献立に入ったので「みんなの定番」に残している（28日を過ぎても一覧に出る）
同意✓＝投稿者が「みんなが見る一覧に載せる」に同意している

読み方のヒント

  • 採用率が高く、候補に出た回数も多い料理は「当たり」です。同じ親の料理（例：しょうが焼き）や同じ投稿者の料理を増やす手がかりになります。
  • 候補に何度も出たのに採用率が低い料理は、利用者に選ばれていません。題名・写真・時間が合っていない可能性があります。
  • 作ったが多い料理は、実際に作られた＝満足度の高い料理です。献立に入った回数より重く見ます。
  • 回数はすべて匿名です（端末ごとのランダムな番号と回数だけ。誰が選んだか・料理名は送っていません）。

下の「月の費用（新着集め）」は、新着集めで AI を使った回数と目安の費用です（AI 1回＝1円で数える。上限は月1,000円）。

まだないもの：採用率をもとに「残す・外す」を決める基準（データがたまってから決める予定）。

2. 📥 集める

YouTube からレシピ動画を探して AI で読み、新着として28日間見せる仕組みの状態です。ふだんは毎朝の自動実行（GitHub の「Weekly trend recipes」）が集めるので、ここで押す必要はありません。「100円分集める」は、まとめて増やしたい時の手動の操作です（費用がかかります）。

  • 目標：見えている新着 約400品（親料理80 × 子5品）。
  • 予算：月1,000円。毎日の自動の分は「月の上限 × 今日の日 ÷ その月の日数」まで（月の前半で使い切らないように）。
  • 利用者の分を残す：アプリ全体の AI の月の回数のうち3割は、利用者の YouTube 読み取りのために残し、新着集めは使いません。
  • 0円のふるい：説明欄に作り方が書いていない動画は、AI で読む前に外します。

3. 休んでいる料理と、毎朝の健康診断

28日を過ぎた新着は消さずに「休んでいる料理」になります。見えている新着が400品より少ない日は、毎朝、休んでいる料理から1日80品まで0円で新着に戻します（日ごとのランダムな順。AI も YouTube の検索も使いません）。

戻す時も、ふだんの決まりは守ります：掲載停止の投稿者は出さない／説明文を30日以内に取り直していること（YouTube の決まり）／1人の投稿者は新着全体の3%まで／同じ親料理は6品まで など。

毎朝の自動実行の最後に健康診断が動き、GitHub の実行の画面（Actions → Weekly trend recipes → 実行を開く → Summary）に表が出ます。

項目意味
今日増えた料理AI で新しく読んで新着に入れた数
今日もう一度並べた料理休んでいる料理から0円で戻した数
休んでいる料理もう一度並べられるのを待っている数（まだ確かめていないものも含む）
うち、確かめ済みで使える料理読み出せて、晩ごはんの料理だと確かめた数。残りは毎日0円で確かめ、使えないものは列から外します
いま見えている新着アプリに出ている新着の数（目安200品・目標400品）
7日以内に見えなくなる料理もうすぐ28日を過ぎて休みに入る数

赤（失敗）になって GitHub からメールが届く時：AI の利用枠や今月の予算が切れて集められなかった／サーバーから返事がない／見えている新着が200品より少ない。
赤にならない（メモだけ）：今日の分の予算を使った（月末まで均等）・利用者の分を残すために止めた、など決まりどおりの止まり方。

4. 🤝 投稿者

献立によく入るのに「みんなが見る一覧に載せる」の同意がない投稿者です。同意をお願いするかは運営が判断して連絡します。

5. 📚 レシピ一覧・🍲 親の料理名

  • 📚 レシピ一覧：新着と、献立に入った・残した料理。行を押すと材料・手順・動画が開き、手順ごとの再生位置（▶ の時刻）を直せます。「手順の時刻の点検（0円）」で、時刻のおかしいレシピを探せます。
  • 🍲 親の料理名：集めた料理を料理名（親）ごとにまとめます（例：塩こんぶ肉じゃが → 肉じゃが）。まちがったまとめ方は「外す」、表記ゆれは「まとめる」で直せます。

くわしい仕様は docs/APP_MAP.md の §45・§46 にあります。
