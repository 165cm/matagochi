# 公開のお知らせ（待機リスト）の設定

LPのメール登録は、**Googleフォーム**に送信して、回答をGoogleスプレッドシートで管理します。
日本語で使えて無料、アカウントはふだんのGoogleアカウントで足ります。フォームの画面は利用者に見せず、LPのデザインのまま登録できます。

## 1. フォームを作る（5分）

1. https://forms.google.com を開き、「空白のフォーム」を作成。タイトルは「リピごち 公開のお知らせ」など。
2. 質問を3つ作る。**すべて「記述式」（短い回答）**にしてください（選択式にすると、LPから送る値と一致しないとき保存されません）。
   - 「メールアドレス」…必須をオン
   - 「人数」…必須はオフ
   - 「登録場所」…必須はオフ（LPのどのフォームから登録されたかが入ります）
3. 右上の歯車（設定）→「回答」で、次の2つは**オフ**のままにしてください（オンだと LP からの送信が失敗します）。
   - 「メールアドレスを収集する」
   - 「回答を1回に制限する」（Googleへのログインが必要になるため）
4. 「回答」タブ →「スプレッドシートにリンク」で、一覧をスプレッドシートに保存。

## 2. 開発者に渡す情報

フォーム右上の「︙」→「事前入力したURLを取得」を開き、3つの質問に適当な文字（例：a、b、c）を入れて「リンクを取得」→「リンクをコピー」。
そのURL（`https://docs.google.com/forms/d/e/…/viewform?usp=pp_url&entry.123…=a&entry.456…=b&entry.789…=c` の形）を送ってください。
URLから次の値を `lp/waitlist.js` の `WAITLIST` に設定します。

```js
const WAITLIST = {
  action: "https://docs.google.com/forms/d/e/＜フォームID＞/formResponse",
  fields: { email: "entry.＜メールの番号＞", household: "entry.＜人数の番号＞", source: "entry.＜登録場所の番号＞" },
};
```

未設定のあいだ、LPのフォームは「受付の準備中です」と表示し、何も送信しません。

## 3. 公開のお知らせを送るとき

- スプレッドシートの一覧をCSVで書き出し、日本語対応のメール配信サービス（例：Benchmark Email、ブラストメール、配配メールなど）に取り込んで送るのがおすすめです。配信停止リンクや、到達率の管理を任せられます。料金・無料枠は各サービスの最新情報を確認してください。
- 少人数のうちはGmailでも送れますが、**宛先をBCCにし、1通ずつ個別に送る**など、他の人のアドレスが見えないようにしてください。
- 日本の特定電子メール法に沿って、メールには**送信者名・連絡先・配信停止の方法**を必ず書いてください。LPの登録は「公開のお知らせと開発のようす」を送ることへの同意として案内しています（LPのFAQ「メールアドレスはどう扱われますか？」）。
- 配信停止の申し出があったら、スプレッドシートからその行を削除してください。
