# 無料・有料の境界（正本）

最終更新：2026-11-14（ユーザーの判断で、食い違っていた資料を1つにそろえた）。**無料とリピごちプラスの中身・価格・お試しは、この資料が正本**。ほかの資料（`PRODUCT.md`・`PERSONALIZE_PLAN.md`・`APP_MAP.md` §26）は、ここを指す。変える時は、まずここを直す。

いまはベータ版で、**全機能が無料**。有料の仕組みは止めてある（`plus.js` の `GATING_LIVE = false`）。導入の前に、対象の機能と条件を利用者に案内し、同意なく課金しない。

## いまのプログラムとの違い（作り直しが必要）

`plus.js` に作ってある仕組みは、**以前の設計（無料は週3日まで・残りの日はロック・プラスは「毎日の献立」）**のままで、上の決めたこととは逆向き。止めてあるので利用者には見えない（`?paywall=1` の確認用だけ）。決済を動かす前に作り直す。

| 場所 | いまの中身 | 直す先 |
|---|---|---|
| `plus.js` `FREE_DAYS`・`lockedDates`・ロックの帯 | 週3日まで・曜日のロック | 無料＝今夜の1品（今日タブ）、まとめて決める操作と買い物リストの一本化をプラスに |
| `plus.js` `PLUS_PERKS`・`PLUS_FROM` | 「毎日の献立」「家族で共有」「いつでも解約」 | まとめ献立・まとめ買い物・使い回し（家族で共有は無料） |
| `plus.js` `trialPlan`・`state.trialFrom` | 初回設定を終えた日から自動・端末で管理・延長なし | 本人の操作で開始・サーバーで管理・延長1回 |
| お休み週 | なし | 新しく作る |

## LPと実装の対応

- `?start=quick`：3画面の設定・調整。人数、平日の調理時間、食べられない食材。初期提案期間は3日。休日の時間などは未指定のまま。詳細設定が完了したことにはしない。
- `?start=preview` と初回の「まずは見てみる」：用意されたレシピから3日分を表示。サンプルの記録・献立確定データは投入しない。既存データは消さない。既存利用者も3問から条件を調整でき、記録・確定済み献立・その他の設定は保持する。プレビューから3問へ進める。
- 確定前の料理は買い物リストに入れない。3問で無条件に3品そろうとは保証しない。
- 詳細16画面と診断は継続して利用できる。
- LPの今日・献立画像は `scripts/check-lp.cjs` で隔離した利用例から実画面を撮影。装飾用の架空UIを混ぜない。

## データ表現

基本は端末内保存。同期は共有対象データをサーバーへ送信・保存し、AI取り込みは入力URLや解析画像などを送信してAIサービスで処理する。外部画像・動画、URL情報取得、共通レシピ照会・修正提案にも通信があるため、「同期・AI以外は一切通信しない」とは書かない。個人の診断・食材制限は家族同期対象外だが、バックアップには含む。
