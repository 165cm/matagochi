# 無料・有料の境界 / 2026-09-23

LPで約束する無料の基本機能は、レシピの保存・編集、食事の記録、JSONバックアップの書き出し・読み込み。将来の有料導入後もこれらを無料で継続する。今回、課金処理・ペイウォール・件数制限は導入しない。

現在は全機能を無料提供。有料候補は豊富な提案レシピの提供、AI取り込みの利用枠拡張、端末間同期。価格（980円は検討案）・開始時期・無料枠・既存利用者の移行条件は未決定。既存の全機能を永久無料とは約束しない。導入前に対象機能と条件を案内し、利用者の同意なく課金しない。AIの運用上の実行上限は無料という表現でも解除されない。

## LPと実装の対応

- `?start=quick`：3画面の設定・調整。人数、平日の調理時間、食べられない食材。初期提案期間は3日。休日の時間などは未指定のまま。詳細設定が完了したことにはしない。
- `?start=preview` と初回の「まずは見てみる」：用意されたレシピから3日分を表示。サンプルの記録・献立確定データは投入しない。既存データは消さない。既存利用者も3問から条件を調整でき、記録・確定済み献立・その他の設定は保持する。プレビューから3問へ進める。
- 確定前の料理は買い物リストに入れない。3問で無条件に3品そろうとは保証しない。
- 詳細16画面と診断は継続して利用できる。
- LPの今日・献立画像は `scripts/check-lp.cjs` で隔離した利用例から実画面を撮影。装飾用の架空UIを混ぜない。

## データ表現

基本は端末内保存。同期は共有対象データをサーバーへ送信・保存し、AI取り込みは入力URLや解析画像などを送信してAIサービスで処理する。外部画像・動画、URL情報取得、共通レシピ照会・修正提案にも通信があるため、「同期・AI以外は一切通信しない」とは書かない。個人の診断・食材制限は家族同期対象外だが、バックアップには含む。
