# 初期レシピ38品と候補不足時の献立

2026-09-23: 既存12品にレビュー済み recipe/v2 の26品を追加。
`starter-recipes.js` はレビュー済み材料・工程と流行根拠の確認状況を保持する。
流行の根拠は手順の出典ではなく、未確認の順位や再生数をアプリに表示しない。
調理時間は試作前の目安。炊飯・解凍は別途。食品用温度計は共通用品として作り方画面で案内する。

材料の allergens と label_check の両方を除外判定に使う。
既存12品のツナ・油の大豆、みその魚も判定へ補足。
ケチャップ・中濃ソースのトマト、みそのきのこだし等も苦手食材として保守的に扱う。
耐熱ボウル・キッチンばさみは初期設定で「ある」。回答済みの「なし」「未確認」は保持。

献立は条件に合う未使用の料理を優先し、不足した時だけ既出の候補を再利用する。
再利用時も食材・時間・器具・作業・リピなしの制約は緩めない。適合候補が0品なら空欄のまま案内する。
確定済みの献立スナップショットは更新しない。重複した各日の材料は買い物リストで合算する。

検証: node --test test/*.test.cjs、npm test --prefix api。
