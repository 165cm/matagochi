# タイムコード品質改善の全体計画

2026-11-05。品質改善を4段階に整理する。取得率90%は目標であり、達成済み・保証済みではない。

1. 誤った成功判定を止める（PR #231公開済み）。既存の逆転・重複を補完開始時に検出し、空欄が埋まっただけで成功としない。
2. 点検・追跡を整える（PR #232公開済み）。保存直前の全体検査、拒否した候補を含む試行記録、既存補完動画の点検、健康診断の品質集計。管理者確認状態は #229 で公開済み。
3. 生成方法を改善する（実装中・実動画の生成結果評価は未実施）。サバ味噌煮など問題動画を動画・字幕と照合し、説明欄の手順順序と動画順序の差を特定。問題動画は手順と時刻を一緒に再構成する候補を作り、確認後採用。説明欄の材料・分量を守る。検査を通るためだけの時刻並べ替え・補間はしない。実装前に少数の正解例・許容ずれ・手順分割基準を確定する。
4. 精度・費用を実測して運用を広げる（未着手）。固定50本で、全手順の時刻付与率と場面一致率を別々に評価。成功1本あたりの費用、要手直し率、失敗原因も計測。基準未達なら3へ戻る。試験累計500円を継続し、予算拡大は別途判断する。

段階3の完了条件は、問題の代表例で手順・時刻の対応が改善したことを人が確認し、回帰検証できること。段階4の完了条件は、評価対象・許容誤差・結果・費用を報告し、自動採用してよい条件を決めること。

4段階は目的の区切りであり、PRが4本で終わるという意味ではない。管理画面・スマホ表示・導線の修正は点検を支える付随作業。
