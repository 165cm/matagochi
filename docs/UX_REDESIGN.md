## いまの画面で起きていること（2026-11-15 の版を 390×844 で動かして確認）

1. **献立タブに見た目のちがう2つの世界**：上は白い献立カード、下は茶色のカード（No.・技★・作った まだ）。決める前の献立タブは縦に約2,100px。決めたい人に、集める情報が先に入る
2. **料理を変える方法が2つ**：今回の分は「🔄 選び直す」→ 下のカード →「◯曜へ」。次回の分と今日タブは「⇄ 変更」→ 写真4枚 →「✕ パス」（§64）。決定ボタンも「この3日分で決定・買い物へ」と「月〜水をこれで決定」の2種類
3. **はじめての画面に献立が見えない**：「最初の献立ができました！」の下に、好みに寄せるボタン6つと招待の案内が先に並び、3日分は最初の画面の外。画面の下に貼りついたよはくの吹き出しが、料理や候補カードに重なる
4. **レシピタブが一覧だけ**：献立とも図鑑ともつながって見えない。図鑑はふりかえりタブ →「🃏 図鑑」の奥
5. **決めた瞬間の安心が出ていない**：決定を押すと買い物リストに切り替わるだけ。プラスの価値（考える手間・使い回し）が言葉になっていない

## 新しい案

### 1. 献立タブは「見る → 決める」だけ

- 献立カード（写真・日付・時間・料理名・**理由1行**・「変える」）と、決定ボタン1つ
- 決定ボタンの下に1行：「🛒 買う物 ◯品　🧺 使い回し キャベツ・玉ねぎ」
- 「好みに寄せる」（§71）は「ちょっと違う？ 好みに寄せる ›」の中へ
- ふだんは出さない：候補カードの棚・気分の札・「空にする」・貼りついたよはくの吹き出し

### 2. 料理を変える方法は、写真4枚の1つだけ

- どの日でも・今日タブでも、「変える」で同じ画面（今夜の4皿。§64）が下から出る。写真を押すとその日に入る・「✕ パス」・気分の札・「🔄 別の4皿」・「📖 レシピの棚から選ぶ ›」
- 下書き（まとめて決定する前は本番の献立・買い物・家族の同期を書き換えない。§67-1）の安全なしくみは残す。なくすのは、献立タブに並べる茶色い候補カードと「◯曜へ」「🔍 似た皿」のドック

### 3. 決定した直後のまとめ

- 「水曜まで、もう考えなくて大丈夫」＋3品の写真＋「🧺 キャベツ1/2玉を月・水で使い切り」「🧂 ◯品は家にある物で」＋［🛒 買う物 ◯品を見る］［あとで見る］
- 数字と品名は、すでに計算しているものだけ（使い回し・買い物リスト・常備品）。新しい推定はしない

### 4. レシピタブを「わが家の図鑑」に

- レシピタブの切り替えを「🃏 図鑑 48品／🔖 わたしのレシピ」に。図鑑（§70：◯/48・6章・ランクの枠）をここへ引っ越す
- 茶色いカードの見た目は、図鑑・カードの裏・GET の知らせだけで使う
- まだのカードも絵は灰色にせず見せる（次に作る料理を選べる）。どのカードからも「🗓 献立に入れる」
- 集めた動画・自分のレシピは「わたしのレシピ」（今の検索・しぼりこみはそのまま）
- ふりかえりタブには、今週のレシート・わかってきたこと・カレンダー・写真を残す

### 5. はじめての人には、まず献立

- 8つの質問の直後の画面は、「🎉 3日分、決まりました」＋献立カード3枚＋決定ボタン。お祝いの大きな見出し・調整ボタン・招待は先に出さない
- 招待の案内は、決定した後（決定直後のまとめの下か、今日タブ）

## 5つのタブの役割

| タブ | ひとことで | 変えること |
|---|---|---|
| 今日 | 今夜の一皿と、作り方 | ほぼそのまま。「変える」が共通の写真4枚に |
| 献立 | 数日分を見て、決める | 候補カードの棚をなくす・理由1行・決定1つ・決定後のまとめ |
| 買い物 | 買う物だけ | そのまま |
| レシピ | わが家の図鑑と、自分のレシピ | 一覧を図鑑に・「献立に入れる」をどのカードにも |
| ふりかえり | 食べた記録と、わかってきたこと | 図鑑はレシピへ引っ越し |

## 「払ってもいい」と思える3つの瞬間

| いつ | 気持ち | 画面 |
|---|---|---|
| はじめて開いて1分 | わかってくれてる | 自分の条件で選ばれた3日分が、理由つきで最初に見える |
| 決定を押した瞬間 | 今週はもう考えなくていい | 安心のひとこと・使い回せる食材・買う物の数 |
| 2週目から | うちの図鑑が育っている | 作るたびにレシピの棚のカードが金色に |

プラスの案内を出す場面・価格・無料との境界は `docs/FREE_PAID_BOUNDARY.md` のまま変えない。
