## 大事な決めごと

- PR 4・PR 7 の判断（2026-10-01）：基本のレシピは YouTube から／同意のない動画は新着として28日・ランダムに見せ、献立に入れたものはその人の保存として残す／品数は採用率の基準で残す料理を決め、まず4週間かぶらない量／費用は収益の1％以内ならまず集める／お試しは本人（アカウント）単位・2週間・キャンセル時に最大2週間延長／採用された新着はみんなの定番にも残す（YouTube の30日・停止のルールは守る）／β版の集める費用は月1,000円まで／延長はお試しの終わりに1回だけ提案／プラスは同期している家族の端末でも使える（詳しくは `docs/PERSONALIZE_PLAN.md` §2）
- 親の料理名（親子・2026-10-01）：集めた料理は料理名（親）と作り方（子）に分ける／アレンジも同じ親／自動の献立は同じ親を週1回まで、自分で選ぶ（食べ比べ）は制限しない／子の評価は親に連動（子の「もう作らない」はその作り方だけ、親の「もう作らない」は親の画面で選んだ時だけ）／親の辞書は、辞書にない料理名が3本以上・投稿者2人以上でそろったら自動で格上げ（管理の画面で外す・まとめる）（APP_MAP §48）
- 運営者の本名は公開のページ・開発メモに出さない（「リピごちの運営者」。氏名・住所・電話番号は請求があれば遅滞なく開示。2026-09-30 決定）
- 投稿者の本人確認は YouTube へのログインで行う。参加申請は承認画面で運営（ユーザー）が手で確認する（2026-09-30 決定。APP_MAP §40）
- 文字は最小限・説明は ⓘ・絵文字＋短い言葉（`docs/UI_RULES.md`）
- よはくは1画面に1匹・UIとの間24px以上・高さを取らない
- 評価は毎日聞かない（ひと回りでまとめて）
- 料理中：動画はその手順の場面をいつもくり返す。チェックボックス・1手順ずつの大きな文字の画面は使わない（以前ためして、不評でやめた）
- 本番公開の前に必ずユーザーに確認する
- ベータ版は無料（`GATING_LIVE=false`）。Stripe は正式版で
- 動画の自動取り込みは YouTube だけ。本番マージ・デプロイ・`GATING_LIVE` の本番有効化・実決済・価格の確定・投稿者への連絡・権利不明の動画の大量AI解析は、承認されていない（`docs/PERSONALIZE_PLAN.md` §2）

## 変えてはいけないもの

- localStorage のキー `matagochi-mvp-v1` と公開URLのパス `/matagochi/`（既存ユーザーのデータが消える）
- `state` の主な項目名と、レシピ・記録の形（`recipes` `mealSlots` `evaluations` `familyRepeatCycles` `shoppingMarks` など。足すのはよいが、名前を変えたり消したりしない）

- 同期の部屋の決め方（合言葉から `deriveSyncRoomId`）

- 開発用の解除コード（`DEV_UNLOCK_CODE`）の値は、どこにも書かない
