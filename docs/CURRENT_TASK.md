## 大事な決めごと

- 文字は最小限・説明は ⓘ・絵文字＋短い言葉（`docs/UI_RULES.md`）
- よはくは1画面に1匹・UIとの間24px以上・高さを取らない
- 評価は毎日聞かない（ひと回りでまとめて）
- 料理中：動画はその手順の場面をいつもくり返す。チェックボックス・1手順ずつの大きな文字の画面は使わない（以前ためして、不評でやめた）
- 本番公開の前に必ずユーザーに確認する
- ベータ版は無料（`GATING_LIVE=false`）。Stripe は正式版で

## 変えてはいけないもの

- localStorage のキー `matagochi-mvp-v1` と公開URLのパス `/matagochi/`（既存ユーザーのデータが消える）
- `state` の主な項目名と、レシピ・記録の形（`recipes` `mealSlots` `evaluations` `familyRepeatCycles` `shoppingMarks` など。足すのはよいが、名前を変えたり消したりしない）
- APIのルートとレスポンスの形（古い版のアプリも同じAPIを使う）
- 同期の部屋の決め方（合言葉から `deriveSyncRoomId`）
- プライバシーの約束：腕前判定の写真はサーバーに保存しない／✋のカメラ映像は端末の外に送らない／集計に名前・料理名を送らない（`legal/privacy.html`）
- 開発用の解除コード（`DEV_UNLOCK_CODE`）の値は、どこにも書かない
