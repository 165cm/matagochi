# リピごち：何を作っているか（PRODUCT）

## ひとことで

**「今日なに食べる？」を、過去の食卓から決める。**
1人・2人暮らし（と小さな家族）の夜ごはんを、好み・時間・器具・常備品・「また食べたい」周期から数日分決め、買い物と「作った」の記録までつなげる PWA。

## 中心のループ

```
決める（献立） → 買う（必要な物だけ） → 作る（動画と手順） → 「また食べたい」を人ごとに → 次の提案が賢くなる
```

- 献立の理由を1行で見せる（「ふたりの好物・8日ぶり」「肉続き → 魚」「🍂 旬の鮭」）
- 評価は毎日聞かず、献立のひと回りが終わったらまとめて（比べて評価）
- 評価から「わかってきたこと」（人ごとの好み・定番）を見せる
- SNS（YouTube・TikTok・Instagram）のレシピ動画の取り込みは**入口の一つ**で、主役ではない

## 強み（ほかのレシピアプリとの違い）

- 自分が保存した**よその動画**を、手順ごとの場面で見ながら作れる（🍳料理モード：その手順の場面をくり返す・手順ごとの材料・✋手の形で操作）
- 家族ひとりずつの「また食べたい」周期で、飽きずにくり返す
- 文字が少なく、スマホ1画面で完結

## やらないこと（追いかけない）

- タイマー以外の重い料理ツール（単位換算・栄養計算・在庫管理）を競合に合わせて増やすこと
- 献立表のイラスト生成（試したが再現度が足りず止めた。コードは残してある：`weekly.js` の `MENU_ENABLED=false`）
- 動画をアプリ内に保存すること（再生は公式の埋め込みプレーヤー。再生回数・収益への反映は YouTube の仕組みによるので、「必ず増える」とは言わない）

## いまの段階（ベータ）

- ベータ版は無料。有料ボタンを押すと、お礼と意見フォーム → 正式版で3か月無料の招待コード
- 無料／有料（リピごちプラス：1年6,000円／4週600円）の出し分けは作ってあるが止めている（`plus.js` の `GATING_LIVE=false`）
- AIの読み取りはチケット制（`api/src/tickets.js`）。説明欄は無料、動画から読むのは1枚
- 使われ方は匿名で集計（端末ごとのランダムな番号・回数だけ。名前や料理名は送らない）
