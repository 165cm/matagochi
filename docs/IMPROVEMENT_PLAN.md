# 無料MVP改善計画

## 方針

一人暮らし・二人暮らしの夜ごはんを1日1品で決める。主菜・副菜・汁物のセット生成を入れない。既存の保存・編集・記録・同期・バックアップ・PWAは無料のまま維持する。

## 今回の実装

- YouTube動画IDの正規化、GCSでの分析結果再利用、同時分析の排他、日次・月次回数上限、緊急停止。
- 共通レシピと保存済みマイレシピの分離。材料・分量・手順の編集、元レシピの人数確認。
- 修正提案と管理者承認、版管理、比較して任意取り込み。詳細はRECIPE_DB_POLICY.md。
- 初期設定を1人にし、1人分・2人分の選択を追加。献立を夜ごはんだけの7日分に絞る。
- 取り込み・同期・編集・分量換算・献立の回帰テスト、LP・仕様の整合。
- 画像最大5枚の選択・撮影・縮小・並べ替え・メタデータ除去、Geminiへの画像解析、確認編集、キャンセル、同一セッション内の再送制御。

## 公開前の作業

本番のGCS/IAM、管理トークン、回数上限、クラウド予算アラートを設定し、APIを先にデプロイする。実サービスのYouTube/Gemini/GCS疎通確認後にフロントを公開する。今回のローカルテストでは実際のAI課金は発生させない。

## 後続の初回改修トラック

画像AI取り込みの実装とモックでの回帰検証は完了。実Geminiでの精度・処理時間・原価評価、iPhone/Androidの実カメラ検証を公開前に実施する。私的画像は共通DBへ保存せず、URLキャッシュで画像の内容を置き換えない。

元レビューのP0-2は「同期・写真の再設計」であり、画像AI取り込みとは区別する。同期写真のBlob化・認証付き招待への移行は別の設計・移行作業として管理する。

決済・ペイウォール・保存件数制限・複数品の献立・在庫最適化・Push通知は今回の対象外。実装済みと未実装をLPで混同しない。
