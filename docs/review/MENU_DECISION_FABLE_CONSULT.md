## 0. お願いしたいこと

スマホの献立アプリ「リピごち」で、**献立を決める体験**を作り直してきました。仕組みは一通り動くようになりましたが、開発者が自分で使ってみても、**まだ「気持ちよく決められた」という体感になりません**。

細かい部品の案よりも、まず **「なぜ気持ちよくないのか」の見立て** と、**体験の芯をどう作るか** を一緒に考えてほしいです。今の作りを捨てる案も歓迎します。

## 1. アプリの前提（30秒で）

- 一言：「今日なに食べる？」を、過去の食卓から決める。1人・2人暮らし（と小さな家族）の **夜ごはん1品（主菜）**。スマホのWebアプリ
- 流れ：**決める → 買う（必要な物だけ）→ 作る（YouTube のレシピ動画を見ながら）→「また食べたい」を人ごとに記録 → 次の提案が賢くなる**
- 料理：運営が YouTube から集めた新着レシピ 約400品（28日で入れ替わる）＋みんなの定番20品＋最初から入っている48品＋自分で保存したレシピ
- 使う人：仕事帰り・子育て中で、考える気力が残っていない人。IT が苦手な人も多い
- 守ること：食べられない食材・器具・時間の条件はゆるめない／文字は最小限・専門用語なし／1画面に目的は1つ・ボタンは高さ44px以上／AIの費用は月1,000円まで（並べ方はスマホの中の計算だけ）／好みのデータはスマホの中だけ／家族の「見るだけの人」も1タップで済む

## 2. このやりとりで目指していること（目的）

1. **決めるのがラク**：自動の提案に「これでいい」と言える。変える時も数タップ・数秒で「これ食べたい」に届く
2. **気持ちいい**：選ばされた感ではなく「自分で選んだ」感。決めた時に小さな満足がある
3. **近づいていく手応え**：変えるたびに、食べたいものに寄っていく感じがある（ガチャではない）
4. **400品の幅が生きる**：飽きない・新しい出会いがある。でも多すぎて迷わない
5. **使うほど賢くなる**：質問を増やさずに、行動から好みを学ぶ

## 3. いまの体験（公開済み）

**入口**：献立タブは、自動で決めた数日分の料理が並ぶ（写真・料理名・時間・理由の札1つ）。今日タブは「今夜のおすすめ」1品。気に入らない時に「⇄ 変更」を押す。

**「⇄ 変更」の画面（下から出るシート）**
- 上：日付と ✕（閉じる）／気分の札（😋 いつもの・⚡ 15分以内・🥩 肉・🐟 魚・🍋 さっぱり。1つ選ぶとその場でしぼる）
- 秘書のキャラクター「よはく」と吹き出し：開いた時は「食べたくないのは『✕ パス』してね。好みに寄せていくよ」
- 写真4枚（スマホ・2×2・YouTube と同じ16:9）。写真のすぐ下の1行に「⏱15分 · 😋好物」と目立つ「✕ パス」、その下に料理名。広い画面・縦に長いスマホは6枚
- 最初の4枚：好物を1枚（周期が来ていれば）＋主役（肉・魚・卵豆腐・野菜）・食べ方（丼・麺・おかず）・味（和洋中）がなるべく重ならない料理
- **✕ パス**：その1枚だけ入れ替わる（ほかの3枚は残る）。パスした料理と似た料理ほど後ろへ回す（その場だけ。1品では少し、同じ特徴を重ねてパスするほど強く）。2品以上で共通した特徴は、よはくが「こってりの気分じゃないんだね。減らしておくね」と言い、下に「少なめ：[こってり ✕]」
- 「🔄 別の4皿」（4枚まとめて入れ替え。特徴は学ばない）／「↩ 戻す」
- **決める**：写真を押す → レシピ画面 → 下の帯「✓ この料理にする／‹ 4皿に戻る」（決める日なら「🛒 新しく買う：◯・◯」も）
- パスした料理は3日間、自動の献立に出さない。別の日に3回「少なめ」になった特徴は、今日の画面で1回だけ「少なめにしますか？」と聞く

**決めてきたこと（経緯）**
- 第1回：「理由の質問・見出し・最大12品の一覧」をやめ、写真を少しずつ見せる形に
- 第2回：「🔀 ほかの4皿」はガチャで近づかない → 「似た料理で寄せる」が本命という結論
- 開発者の感覚で方向転換：「食べたいものを選ぶより、食べたくないものを消すほうがストレスが少ない」→ 消去法（✕ パス）に
- 第3回：消去法を磨く（決めつけない・強さに上限・どちらが理由か分からない時は弱く）。「🔍 似た料理」はまだ入れない（効果を分けて確かめるため）
- 実際に触った感想で：情報を写真の近くに・パスを目立たせる・よはくに代弁させる・写真からレシピを見て決める

## 4. 開発者の体感（いちばん大事）

- **まだ「気持ちよく決められた」という感じがしない**
- （ここに、使ってみて気になった場面を足してください。例：「開いた瞬間に食べたいものが1枚もない」「パスが作業っぽい」「レシピを開いて戻るのが面倒」など）

## 5. Claude の見立て（仮説。違っていたら捨ててください）

1. **入口が「直す」作業になっている**：体験が「自動の提案 → 気に入らない → 変える」の順なので、最初から「外れを直す」気分で始まる。食べたいものを思い浮かべる楽しさの入り口がない
2. **開いた瞬間の4枚に「自分の」感じが薄い**：散らした4枚は、どれも少しずつ遠い。好物はいつも入るわけではない。最初の1画面で「お、これいい」が起きにくい
3. **パスは「マイナスの作業」**：1回のパスで変わるのは1枚だけ。しかも1品目の効き方はわざと弱いので、手応えが遅い。パスを重ねるほど「消している作業」が続く
4. **決めるまでが遠い**：「これいい」と思っても、レシピを開いて、下の帯で決める必要がある。決めた瞬間の気持ちよさ（ごほうび）がない
5. **1画面に情報が多い**：気分の札・よはくの吹き出し・少なめ・4枚・パス・別の4皿が同時に並び、見るところが多い
6. **数日分を決める場面には向いていない**：1日ずつ「⇄ 変更」を開く形なので、買い物前に3〜5日分を決める時は同じ作業のくり返しになる
7. **写真の質**：新着は YouTube のサムネイルで、大きな文字入りが多い。料理そのものの「おいしそう」が伝わりにくい

## 6. 相談したいこと

1. **気持ちよくない本当の原因**はどこにあると思いますか？（5章の見立ての当たり・外れ、ほかの原因）
2. **体験の芯**：「決める」を気持ちよくする、いちばん大事な一つの考え方は何ですか？（例：直すのではなく選ぶ、比べる、ごほうび、会話、など）
3. **今の作りを生かす小さな直し**と、**作り直すならこうする**案を、それぞれ1つずつ
4. **数日分をまとめて決める場面**（買い物の前）と、**今夜だけ変える場面**は、同じ画面でよいと思いますか？ 分けるならどう分けますか？
5. 「気持ちいい」を、**数字や観察でどう確かめるか**（使われた回数は、開いた・パス・戻す・別の4皿・決めずに閉じた・レシピを開いた・決めた、を数えています。名前や料理名は送っていません）

## 7. 回答のかたち

1. 見立て（原因の上位3つ。なぜそう思うか）
2. 体験の芯（一文で）と、それを形にした画面の流れ（スマホ縦1画面・タップの順）
3. 小さな直し（すぐ試せる）／作り直し案（大きく変える）
4. 数日分と今夜だけ、の扱い
5. 確かめ方（最初の1週間で見る数字・観察すること）
6. 開発者に聞き返したいこと（あれば）
