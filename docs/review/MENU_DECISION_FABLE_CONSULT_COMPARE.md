# 献立決めの体験「気持ちよくない」の相談：3人の意見の比較（2026-11-11）

相談文：`docs/review/MENU_DECISION_FABLE_CONSULT.md`。答えた人：Fable・Codex・Gemini（ユーザーがチャットに貼ったもの。要点をまとめた）。

## 0. 開発者の答え（3人からの聞き返しへの答え）

- いちばん気持ちよくないのは **パスしている最中**：パスしても1枚ずつしか変わらず、**終わりが見えない**（Fable・Codex・Gemini の3人とも同じ答え）
- 「⇄ 変更」を押す時、頭の中は **真っ白**（「これじゃない」とだけ感じている）
- 自動の提案をそのまま受け入れる日は **あまりない**
- 変える時は、**数日分を全部変えてしまう**ことが多い
- 小さな直しでは足りない。**大きく変えてよい**
- 使い始めの人の好みは、**エンタメ要素のある診断**で楽しく集めたい

## 1. 3人とも同じ意見

1. **いちばんの原因は「終わりが見えない」**：パスするたびに空いた枠へ次の料理が入るので、何回押しても決める相手が減らない（Codex がコードで確かめた：`swapSlots` は空いた枠だけ補充し、残りの枠は動かさない）
2. **画面の主役が「✕ パス（いいえ）」になっている**：いちばん目立つのがパスで、「これにする」はレシピの奥にある。「自分で選んだ」満足は「これ！」と押す一瞬に生まれる
3. **決める操作をその場に**：レシピを開かずに「✓ これにする」で決められるようにする（レシピは見たい人だけ）
4. **「いいえ」ではなく「こっち寄り」で寄せる**：前向きな1タップで画面全体が寄ってくる
5. **「数日分」と「今夜だけ」は分ける**（部品は同じでよい）
6. よはくの言葉と画面がずれる（「魚じゃない気分かな？」の横にツナコーンごはん）と「聞いてもらえていない」と感じる

## 3. Claude の見立て

- 3人の答えと開発者の答えから、**原因は「終わりの見えない消去法」でほぼ確定**。部品の直し（ボタンの色・言葉）では足りない
- 開発者は「数日分を全部変える」ことが多いので、**ゴールは「この数日分が埋まる」**。今の「1日ずつ ⇄ 変更を開く」形は、トンネルを日数分くり返す作りになっている（Gemini の指摘）
- 頭が真っ白なので、**言葉の札（肉・魚・さっぱり）より、写真2枚の「どっち？」のほうが選べる**（Fable の指摘）
- Codex の「消したら減る」は小さく試せるが、「真っ白」「全部変える」には届きにくい

## 4. まとめた案：「お盆に3皿」＋「どっち？」

1. **入口**：献立タブの数日分の上に「🍱 選び直す」。押すと1つの画面で、上に **お盆（月・火・水の枠）**＝ゴールが見える。自動の料理が入っていて、残す日はそのまま、「全部選び直す」で空にできる
2. **いまの枠を埋める**：下に **大きな写真2枚の「どっち？」**と ●○○。どちらかを押すと、近い2枚（2回目）→ 近い3枚に「✓ この日に」（3回目）。1〜2回目でも「✓ この日に」で決められる。「どっちも違う」は小さく（2枚とも入れ替え、その特徴は後ろへ）
3. **決めたら次の枠へ**：選んだ料理がお盆に入り、次の日の「どっち？」が始まる。次の日の候補は、前の日と主役がかぶらない・同じ食材を使い回せる料理を先に
4. **お盆が埋まったら**：よはく「3日分そろったよ！ 買うのは◯品」＋「この3日分で買い物へ」（ごほうび）
5. **今夜だけ**：同じ画面で枠が1つだけ
6. **パス・気分の札・別の4皿・少なめ**はこの画面から外す（「どっち？」が同じ役目）。食べられない食材などの条件は今までどおり最初から除く
7. **あとで**：同じ「どっち？」の部品で「よはくの食卓タイプ診断」（使い始めの人・28日ごとの新着）
