## 0. お願いしたいこと

あなたは、スマホの献立アプリ「リピごち」の新機能のブレストに参加するメンバーです。
テーマは **「振り返りタブの『わたしの食卓』を、1週間・4週間・3か月・半年・1年の単位でふりかえる機能（仮称：わたしの食卓レビュー）」** です。

ねらいは2つ：

1. **続ける気持ちを上げる**：料理のバリエーション・栄養・チャレンジ精神などを見せて「続けてよかった」「次はこれをやってみよう」と思える
2. **新しい人に来てもらう**：結果を画像にして SNS（Instagram のストーリーズ・X・LINE など）に投稿でき、見た人がアプリを使い始めたくなる

下の「4. Claude のたたき台」は叩かれるための案です。足す・削る・作り直す、どれも歓迎します。ただし「6. 守るもの」は前提として守ってください。回答の形は「8. 回答のフォーマット」に合わせてください（AIごとの案を並べて比べます）。

## 1. リピごちとは（30秒で）

- 一言：**「今日なに食べる？」を、過去の食卓から決める。**
- 対象：1人・2人暮らし（と小さな家族）の**夜ごはん1品（主菜）**。スマホのWebアプリ（PWA）。ITが苦手な人も多い。
- 中心のループ：**決める（献立）→ 買う（必要な物だけ）→ 作る（YouTube のレシピ動画と手順）→ 人ごとに「また食べたい」頃を記録 → 次の提案が賢くなる**
- 約束：「かぶらない、飽きない、また食べたい。」
- 段階：ベータ版（2026年内は全機能無料）。利用者はまだ少なく、使い始めて1〜3か月の人がほとんど。
- 画面の方針：**文字は最小限・絵文字＋短い言葉・説明は ⓘ**。キャラクター「よはく」（鉛筆のしっぽのおばけ）が1画面に1匹だけ余白にいる。将来は LINE スタンプにして宣伝役にもしたい。

## 3. 端末にあるデータ（レビューに使える材料）

| データ | 中身 | 使える例 |
|---|---|---|
| 作った記録 `evaluations` | 作った日時・料理・人ごとの「次に食べたい頃」（明日でも／毎週／月2回／月1回／しばらく／もう作らない）・写真（任意） | 回数・日数・連続・種類・また食べたい率 |

| レシピ `recipes` | 材料（名前・分量・分類）・調理時間・器具・作り手（YouTube の投稿者）・料理名（親）と作り方（子） | 食材の種類・調理法・作り手の数 |
| 料理の系統（自動判定） | 主食（麺・ごはんもの・パン）・主菜（肉・魚・卵豆腐）・味（和・洋・中）・ピリ辛／さっぱり／こってり | バリエーションの内訳 |
| 技の難しさ | ★☆☆〜★★★ | チャレンジ度 |
| 旬 | 料理・食材の旬の月 | 季節を味わった数 |
| 図鑑 | 48品などのカード（★ GET → ★★ 常連 → 👑 定番） | 新しく集めたカード |
| 栄養・塩分の目安 | 分量が書いてある材料から端末で計算。**人数や分量が不明だと「不明」になる**。カードの裏の補助情報の扱い | 野菜量の目安など（精度に限界あり） |
| 家族 | 人ごとの評価（名前はユーザーが付けた呼び名） | ふたりの好みの重なり |

※ データは基本この端末の中（家族で同期している場合は共有分も）。AI に送らずに計算できるものを優先する。

## 4. Claude のたたき台

### 4-1. 期間とその性格

「わたしの食卓」の上（または「わたしの食卓」の見出しの横）に期間の切り替え：**1週 ｜ 4週 ｜ 3か月 ｜ 半年 ｜ 1年**

| 期間 | 性格・見せ方 | 出すタイミング |
|---|---|---|
| 1週 | 今の「🧾 レシート」を拡張。軽く、毎週 | 金〜日に「今週のふりかえり」 |
| 4週 | 「月報」。献立のリズムが見え始める | 4週ごと（決定の4週目） |
| 3か月 | 「季節」。春夏秋冬の食卓、定番が育った実感 | 季節の変わり目 |
| 半年 | 「ここまでの成長」。初月と最近の比較 | 使い始めて半年 |
| 1年 | 「年間アワード」（年末の総まとめ） | 12月中旬〜1月（**2026年末に間に合わせたい**） |

- 記録が足りない期間は**選べない（グレー）か「あと◯回で見られます」**。少ない記録でも責めない言い方に
- 1年は「使い始めてから1年」ではなく「**2026年のわたしの食卓**」（暦の年）も検討。年末は SNS で振り返り投稿が多い時期

### 4-2. 見せる項目（案）

**A. 続けた（土台）**
- 🍳 作った回数・作った日数／決めた夜のうち作れた割合
- 🔥 続いた週（1回以上作った週が何週続いたか）。途切れても「ここから再開」で責めない

**B. バリエーション**
- 🍽 作った料理の種類数／そのうち**はじめての料理**の数
- 🥩🐟🥚 主菜のバランス（肉・魚・卵豆腐の割合）、🇯🇵🇮🇹🇨🇳 味のバランス（和・洋・中）→ 小さな帯グラフ
- 🥕 使った食材の種類数（「◯種類の食材を使いました」）
- 🍂 旬の食材・料理を味わった数
- 🔁 「リピ」と「新顔」の比率（定番で安心しつつ、ちゃんと冒険もしている）

**C. 栄養（目安・補助。数値で評価しない）**
- 🥬 野菜をしっかり使った日の数（分量が読めた料理だけ）
- 🐟 魚の日の数、たんぱく源のローテーション
- 🌈 食卓の色（使った食材を緑・赤・黄・白・黒に分けた「彩りパレット」）
- カロリー・塩分の合計や「◯点」は出さない（アプリの方針：重い管理ツールにしない・医療判断しない）

**D. チャレンジ**
- 🆕 はじめて作った料理・はじめて使った食材
- ⭐ 技★★以上に挑戦した回数
- 🎬 お世話になった作り手（YouTube の投稿者）の数とトップ3
- 🃏 図鑑に入ったカード・ランクが上がったカード

**E. わが家の発見**
- 😍 「また食べたい」率、新しく定番入りした料理
- 👑 期間のベスト3（偏愛ランキング）
- 💑 ふたりとも「また食べたい」の料理（家族の好みの重なり）
- 🧺 使い回した食材（ムダを減らせた）

**F. 次への一言**
- 「次の4週は、魚をもう1回？」「まだ作っていない図鑑のカード◯枚」など、**次の献立に1タップでつながる**提案を1つだけ

### 4-3. 「わたしの食卓タイプ」（案・遊びの要素）

期間のデータから1つの称号を出す（例：「🧭 冒険家タイプ：はじめての料理が4割」「🏠 定番職人タイプ：殿堂入り3品」「🌈 彩り名人」「🐟 海の幸派」）。SNS で「あなたは何タイプ？」と広がりやすい。
※ 以前「経験値・レベル・バッジ」を外した経緯があるので、**点数や上下のつく称号にはしない**（どれも良いタイプ）。

### 4-4. SNS に投稿する画像

- 端末の中で画像を作る（canvas）。AI・サーバーは使わない（費用0円・写真を外に出さない）
- 形：**9:16（ストーリーズ）**と**1:1（X・LINE・フィード）**の2種類
- 中身：期間・作った回数・種類数・ベスト3の写真・タイプ・彩りパレット・よはく・「リピごち」のロゴと URL（QR）
- 共有はスマホの共有シート（`navigator.share` で画像ごと）。できない端末は「画像を保存」
- **プライバシー**：投稿前にプレビューで「写真を使う／イラストにする」「料理名を出す／隠す」「家族の名前は出さない（固定）」を選べる。既定は家族名なし
- 作り手（YouTube の投稿者）のクレジットを入れると、作り手側にも宣伝になる（作り手が拡散してくれる可能性）

### 4-5. 新しい人の流れ（流入）

- 画像の URL・QR は LP（`/lp/`）の専用の入口へ（例：`/lp/?from=review`）。「あなたの食卓も、1週間ふりかえってみませんか」
- 何回共有されたか・その入口から何人来たかを**匿名で数える**（名前・料理名は送らない。今の集計の約束どおり）
- ハッシュタグ案：`#リピごち` `#わたしの食卓レビュー`
- 年末に「2026年のわたしの食卓」をアプリ内とLPで告知

### 4-6. 段階（案）

| 段階 | 中身 |
|---|---|
| 1 | 期間の切り替え（1週・4週）＋項目 A・B・E ＋ 画像（9:16）と共有 |
| 2 | 3か月・半年・1年（＋「2026年のわたしの食卓」年末版）＋ 項目 C・D ＋ タイプ |
| 3 | LP の入口・集計・作り手クレジット・1:1 画像 |

## 5. 決まっていないこと（特に意見がほしい）

1. **期間の切り替えはどこに置く？** 今の「月の切り替え（‹ 11月 ›）」との関係（月と4週がかぶる）。月の切り替えをやめて期間に一本化すべきか
2. **項目が多すぎないか？** スマホ1画面・文字最小限で、期間ごとに何を見せ、何を削るか。期間ごとに主役を変えるべきか
3. **栄養をどう見せる？** 精度に限界がある中で、うそにならず、続ける気持ちが上がる見せ方
4. **「チャレンジ精神」をどう測る？** はじめての料理・食材・技・作り手以外のアイデア
5. **タイプ（称号）は入れるべき？** 以前ゲーム要素を外した経緯とのバランス
6. **SNS で「思わず投稿したくなる」画像とは？** 見た人が「自分もやりたい」と思う決め手。Spotify Wrapped・Duolingo の年間まとめ・Strava 等の参考と、料理アプリならではの工夫
7. **記録が少ない人（使い始め1〜3か月・週1〜2回しか作らない人）**でも楽しめるか。半年・1年の期間を今どう扱うか
8. **家族で使っている場合**、レビューは誰のもの？（決める人／見る人、ふたりの合算）
9. **流入の仕組み**：画像から来た人が最初に見る画面、紹介の特典（※価格・特典は未承認なので「案」として）
10. **年末（2026年12月）に間に合わせるなら**、最小で何を出すべきか

## 6. 守るもの（前提）

- 文字は最小限・絵文字＋短い言葉・説明は ⓘ。よはくは1画面に1匹
- 経験値・レベル・点数・級のような「上下のつく数字」は戻さない
- 細かなカロリー管理・医療的な判断はしない（栄養は目安・補助）
- 写真・名前・料理名を本人の操作なしにサーバーへ送らない。集計は匿名の回数だけ
- AI の費用はなるべく使わない（レビューは端末で計算できる範囲を優先）
- 既存のデータの名前（`evaluations` `mealSlots` など）は変えない（足すのはよい）
- 料金・特典・本番公開はユーザーの承認が必要（ブレストでは「案」として出してよい）

## 7. 参考にしてよい例

Spotify Wrapped／Apple のフォト「思い出」／Duolingo の年間まとめ／Strava の年間まとめ／Nintendo Switch の1年のふりかえり／家計簿アプリの月報 など。真似ではなく、リピごち（夜ごはん・家族・「また食べたい」）ならではの形を。

## 8. 回答のフォーマット

次の見出しで、日本語で答えてください（長さの目安：全体で 2,000〜4,000字）。

1. **ひとことで**：あなたの案の芯（1〜2行）
2. **たたき台への評価**：残すべき点／削るべき点／危ない点（各3つまで）
3. **期間ごとの設計**：1週・4週・3か月・半年・1年それぞれの「主役の項目」と「見せ方」（表で）
4. **新しい項目のアイデア**：たたき台にないもの（5つ以上。バリエーション・栄養・チャレンジ・家族・季節など）。それぞれ「使うデータ」も
5. **SNS 画像の設計**：画面の構成（上から順に）・投稿したくなる仕掛け・プライバシーの配慮
6. **流入の設計**：画像を見た人 → アプリを使い始めるまでの流れ
7. **「5. 決まっていないこと」への答え**：番号ごとに1〜3行
8. **最小で出すなら（年末に間に合わせる版）**：入れるもの／後回しにするもの
9. **気になるリスク**：続ける気持ちを逆に下げてしまうケースなど
