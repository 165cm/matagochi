## 2. 問題・変更後・含めない範囲
**問題**（§4・§5）
- 方針の会話は平日の話だけで、休日の夜の違い・一緒に食べる人との違いを聞いていなかった
- 最初の提案に「これは違う」と返す手段が「閉じる」しかなく、反応が方針に戻らなかった
- 保存した方針を見直す画面は「確かめる」だけで、本人が言ったこと・献立に使っていること・記録から分かったこと・版の履歴を分けて見られなかった

**変更後**
- `profile-talk.js`
  - 質問を2つ追加：⑥「休日の夜は、平日とちがう？」⑦「一緒に食べる人と、好みはちがう？」
  - 解釈を追加：`weekend-cook`（休日は20分以上の煮込み・焼きもの）・`weekend-quick`（休日も15分以内）。どちらも `days: "weekend"` で、**土日の献立にだけ**加点（`leaner` が `(recipe, date)` を受け取る。日付がない所では使わない）。`life-weekend-out`・`together-diff` は加点しない理解だけ。`life-few`（材料6つ以下）
  - `react(p, {member, kind, at})`：「時間が長い」→ `life-quick`、「材料が多い」→ `life-few` を ✓ にし（`decisions` に `via: "react"`）、版を1つ残す（`reason: "reaction"`）。`via: "react"` の決定は `interpret` が答えと関係なく拾うので、答えを直しても消えない（確かめる画面で ✕ にすれば外れる）
  - `history(p, member)`：版ごとの増えた／減った ✓
  - `normalize`：`via`・`reason: "reaction"`・`stage: "view"`・`session.skip`（文字列80字以内・最新20件）を通す。それ以外は今までどおり落とす
- `lifestyle.js`：`propose` の `preferenceOf(recipe, date)`（日付を渡す）
- `daily-ui.js`：`dailyPlan({ exclude })`（最初の提案で外した料理を候補から除く）
- `talk-ui.js`
  - 最初の提案の下に「変えるなら？」（⏱ 時間が長い／🧺 材料が多い／🤔 気分じゃない）。どれもその料理を外して次の料理。時間・材料は方針に入る（`talk_fixed` を1回だけ）。「気分じゃない」は方針を変えない
  - 「わが家のごはん方針」の画面（`renderTalkView`・`stage: "view"`）：💬 あなたが言ったこと／✓ 献立に使っていること（「変えるなら？」から入ったものに印）／🧪 まだ確かめていない案の数と「確かめる」／✕ 使わないこと／📈 記録から見えてきたこと（`Lifestyle.insights`。期間と件数つき、足りない時は「あとN品」）／🕘 方針の履歴。設定の「見直す」はこの画面を開く
  - 今日の1行の「5問ほど」→「6問ほど」
- `styles.css`：`.talk-react` `.talk-said` `.talk-history`

**含めない範囲（PR 2c 以降）**：共有範囲の選択（家族共有・AI送信）、晩ごはんタイプを方針の画面から開く、サーバーのAI
