## 1. ユーザーが決めたこと（2026-11-23）

1. **料理の絵は「カフェのイラスト風」をAIで作る**。SNS が映えて、投稿した人がうれしくなるように
2. **数字にこだわらない**。見せたいのは「こんなに料理ができる、家庭的な一面」。数字は補足
3. **YouTube のサムネイルは元にしない**。本人の写真か、料理名と材料（文字）から作る
4. **試作（段階0）から始める**。試作の費用は500円まで
5. **写真から作るイラストの回数**：無料の間は「1週・1か月・3か月のレビューで1枚ずつ」のお試し。有料プランは週1回のペースを考える（§5 で費用を試算）

## 3. 第3版の形

### 3-1. 流れ

```
ふりかえり → 「わたしの食卓」の横の 📮 レビュー
  → 期間を選ぶ（今週・1か月・3か月・半年・2026年）
  → 表紙の一皿を選ぶ（アプリがおすすめを1つ選んでおく。変えられる）
  → 絵を選ぶ：🎨 カフェ風イラスト（AI）／📷 写真そのまま／🖼 アプリの絵
  → プレビュー（この時に画像を作っておく）
  → 📤 シェア／保存
```

### 3-2. 画像（9:16・上から）

1. 期間の言葉：「2026年のわたしの食卓」「11月の夜ごはん」
2. **表紙の一皿：カフェ風イラスト（大きく）**。ほかに記録があれば小さく2皿まで
3. **ひとこと**（1行。端末で選ぶ・AIなし）
4. 数字は小さく1行：「38皿・21種類」
5. よはく1匹・「リピごち」の名前（検索で見つかる）・小さなQR
6. 隅に小さく「AIイラスト」（AIで作った時だけ）

- 料理名は既定で出す／隠すを選べる。家族の名前・メモ・評価・撮影日時は描かない
- AIのイラストは「器・背景・光をカフェ風に。料理そのものは変えない」指示にする（うそにしない）

### 3-3. ひとこと（記録から選ぶ。どれも「家庭的な一面」）

| 種類 | 例 | 使うデータ |
|---|---|---|
| おかえり | 「おかえり、肉じゃが。5週間ぶり」 | 同じレシピの前回の日付 |
| ふたりの好物 | 「ふたりの『また食べたい』が3皿」 | `latestRatings`（回答した人だけ） |
| ラクした夜 | 「15分ごはんに助けられた夜が6回」「洗い物少なめの夜が4回」 | 調理時間・器具 |
| はじめて | 「はじめての料理に4回」 | 料理名（親）で初登場 |
| 季節 | 「きのこと煮込みで、あったかい秋」 | 日付・旬の印 |
| 使い回し | 「キャベツを3つの料理に」 | 材料名（節約額には換算しない） |
| 野菜 | 「14種類の野菜を使いました」 | 野菜の種類（分量は問わない） |

候補が多い時は、期間ごとに優先する種類を決めて1つだけ出す。

### 3-4. 期間ごとの主役

| 期間 | 対象の日 | 主役（表紙のおすすめ） | 優先するひとこと |
|---|---|---|---|
| 今週 | レシートと同じ週（月〜木は先週） | もう一度食べたい一皿 | ラクした夜・ふたりの好物 |
| 1か月 | 暦の月（11月など） | 何度か作った一皿 | おかえり・はじめて |
| 3か月 | 暦の3か月 | 季節の一皿 | 季節・野菜 |
| 半年 | 暦の6か月 | 久しぶりに戻ってきた一皿 | おかえり・使い回し |
| 2026年 | 1〜12月（途中から使い始めた人は「11月〜」と書く） | 今年もう一度食べたい一皿 | ふたりの好物・はじめて |

- **4週ではなく暦の月にする（提案）**：SNS では「11月の食卓」の方が伝わりやすく、ふりかえりタブの月のカレンダーともそろう
- 記録が0件の期間は選べるが「まだ記録がありません」＋記録への入口。1件から作れる。「あと◯回で解放」は出さない

## 4. カフェ風イラストの作り方

| 元 | 作り方 | 誰の費用 |
|---|---|---|
| 本人の写真 | 本人が「🎨 イラストにする」を押した時だけAIへ送る。サーバーに保存しない。作った絵は端末に保存（同じレビューで作り直さない） | 1枚ずつ（回数の上限つき） |
| 写真がない料理 | 料理名と主な材料から作る。**同じ料理（親）の絵はみんなで使い回す**。図鑑・みんなの定番の料理は先にまとめて作っておく | 料理ごとに1回だけ |

- 献立表のイラスト生成は「似ていない」で止めた（APP_MAP §24）。原因は複数の料理を1枚に描かせたこと。今回は**1皿ずつ作って、並べるのは端末**
- AI の月の上限（`AI_MONTHLY_LIMIT`＝1,600回。取り込み・新着集めの分）とは**別の枠**にして、イラストが取り込みの回数を食わないようにする
- プライバシーポリシーに「写真をイラストにするためにAIへ送る・保存しない」を足す

## 5. 費用

### 5-1. 試作の500円で何をするか（段階0）

試作だけの費用。本番の機能づくりは含まない。

- あなたの写真3枚 × 絵柄3通り（カフェ風の明るい・落ち着いた・手描き風など）＝ 9枚
- 文字だけの5品 × 絵柄3通り ＝ 15枚
- 気に入らない分の作り直し、もう一つのAI（モデル）との比べ ＝ 十数枚
- **合計40枚前後**。1枚の値段・かかった時間・「料理が変わっていないか」を記録して、あなたが見て決める
- 500円に届きそうになったら、その時点で止めて報告する

### 5-2. 有料プランで週1回はペイするか（試算）

- 1枚の値段は試作で実際に測る。**以前の世代の画像AIは1枚およそ6円**だった（今の値段は試作で確かめる）
- 週1回 ＝ 4週で4〜5枚 ＝ **約30円**
- プラスは4週600円（年払いなら4週あたり約460円）→ 売上の**5〜7%**。**赤字にはならない**
- ただし、取り込みのAI・決済の手数料も同じ売上から出るので、最終的な上限は試作の値段を見て決める
- 無料のお試し（1人3枚）は1人あたり約20円。広告費と考えれば安い。ただし、たくさんの人が使い始めた時のために、月の合計の上限（例：月◯円まで。超えたら「アプリの絵」で作る）を置く

## 6. 段階

| 段階 | 中身 | 目安 |
|---|---|---|
| 0 | **イラストの試作**（§5-1）。あなたが見て、絵柄と「続けるか」を決める | すぐ |
| 1（年末） | 📮 レビュー：**2026年・今週・1か月**。表紙の一皿を選ぶ・ひとこと・数字1行・9:16 画像・共有／保存（iPhone の対策つき）・LP の歓迎の帯（`?from=review`）・リンクのコピー。絵は「写真そのまま／アプリの絵／**共通のカフェ風イラスト（文字から・先に作っておく）**」 | 12月中旬 |
| 2 | 写真から作るカフェ風イラスト（お試しの回数つき）・3か月・半年・1:1 画像 | 年明け |
| 3 | 作り手のクレジット・匿名の集計（共有した回数・入口から来た人数）・有料プランの回数 | 正式版と一緒 |

- 段階1で共通のイラストを先に作る費用（図鑑・みんなの定番の料理 × 1枚）は、試作で値段がわかってから見積もって、あらためて承認をもらう

## 7. 次にユーザーに決めてもらうこと

1. 「4週」ではなく「1か月（暦の月）」にしてよいか
2. お試しの回数の読み方：「1週・1か月・3か月のレビューで1枚ずつ（全部で3枚）」で合っているか。それとも「毎週1枚・毎月1枚・3か月ごとに1枚」のくり返しか
3. 試作に使う写真3枚（料理の写真。人や部屋が写っていないもの）を用意してもらえるか
