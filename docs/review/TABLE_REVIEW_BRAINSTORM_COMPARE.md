## 1. ユーザーの意見（2026-11-23）— いちばん優先する

1. **料理の画像を「おしゃれなカフェのイラスト風」にAIで作る**。ユーザーが撮った写真（や YouTube のサムネイル）を参考に、予算の中で。投稿した人の SNS が映えて、承認欲求が満たされるように
2. **数字にこだわらない**。SNS で見せたいのは「こんなに料理ができる、家庭的な一面」。数字は読ませるための補足として小さく添える

→ たたき台の「数字・内訳・タイプ」が主役の設計から、**「絵（食卓のイラスト）＋ひとこと」が主役、数字は1行の補足**に組み替える。

## 3. 第2版の方針

### 3-1. 主役は「わたしの食卓のイラスト」と「ひとこと」

SNS 画像の構成（9:16・上から）：

1. 期間の言葉：「2026年 秋のわたしの食卓」「今週の夜ごはん」
2. **カフェ風イラストの料理（1〜3皿。品数でレイアウトが変わる）**
3. **ひとこと**（データから端末で文を選ぶ。AIは使わない）：例「きのこと煮込みで、あったかい秋でした」「ふたりの『また食べたい』が3皿も」「はじめての料理に4回挑戦」
4. 小さく数字1行：「12皿・9種類・野菜14種類」
5. よはく＋「リピごち」と QR

- アプリ内のレビュー画面も同じ順（絵 → ひとこと → 数字）。内訳（肉・魚・卵豆腐や和洋中の帯）は画面では「くわしく ⓘ」に入れ、画像には出さない
- 「タイプ（称号）」はやめて、「ひとこと」に吸収する（上下がつかず、家庭的な一面を見せる言葉の方が意見1・2に合う）

### 3-2. カフェ風イラストの作り方（案）

| 元にするもの | 作り方 | 費用 | 判断 |
|---|---|---|---|
| **本人が撮った写真** | 本人が「イラストにする」を押した時だけ、写真をAIに送ってイラストに。サーバーには保存しない（腕前判定と同じ扱い） | 1枚ずつかかる。人ごとに回数の上限 | **使う** |
| **写真がない料理** | 料理名・主な材料（文字）からイラストを作る。**同じ料理（親）のイラストはみんなで使い回す** | 料理ごとに1回だけ。図鑑・定番の料理は先に作っておける | **使う** |
| YouTube のサムネイル | — | — | **使わない**：サムネイルは作り手の作品で、それを元にした絵は権利の心配がある（「権利不明の動画の大量AI解析」は未承認）。さらに canvas の制限で技術的にも描けない |

- **以前の失敗を繰り返さない**：献立表のイラスト生成は「再現度が足りない」で止めた（APP_MAP §24）。原因は「複数の料理を1枚に」。今回は**1皿ずつ作って、並べるのは端末**（§24 の「再開するなら写真1枚ずつ」と同じ方向）
- **うそにしない**：写真から作る時は、盛り付け・器・背景だけをカフェ風にし、料理そのものは変えない指示に。画像の隅に小さく「AIイラスト」
- **費用**：AIの月の上限（いま1,600回・`AI_MONTHLY_LIMIT`）とは別の枠にするか、内側に入れるかは決める。1枚の単価は**試作で実際に測ってから**決める（記憶の値段では決めない）
- プライバシーポリシーに「写真をイラストにするためにAIへ送る・保存しない」を足す必要あり

### 3-3. 期間ごと（簡略版）

| 期間 | 主役 | ひとことの例 |
|---|---|---|
| 1週 | 今週の3皿 | 「今週は魚が2回。えらい」 |
| 4週 | ベスト3と、はじめての料理 | 「はじめての料理に2回挑戦」 |
| 3か月 | 季節の食卓（旬の料理） | 「きのこと煮込みで、あったかい秋」 |
| 半年 | 最初の頃の一皿と、いまの定番 | 「◯◯が、わが家の定番になりました」 |
| 1年（2026年） | 今年の一皿（1件でも作れる） | 「今年もう一度食べたい一皿」 |

### 3-4. 段階（第2版）

| 段階 | 中身 | AI |
|---|---|---|
| 0 | **イラストの試作**：本人の写真3枚・文字だけ5品で作って、見た目（映えるか・料理が変わっていないか）と1枚の費用を測る。ユーザーが見て決める | 試作のみ |
| 1（年末に間に合わせる最小） | 「2026年のわたしの食卓」＋1週・4週。絵（まずは文字から作った共通のイラスト＋本人の写真そのまま）＋ひとこと＋数字1行。9:16 画像と共有（2段階）。LP の入口 `?from=review` | 共通のイラストだけ |
| 2 | 写真から作るカフェ風イラスト（本人が押した時だけ・回数の上限）、3か月・半年、1:1 画像 | あり |
| 3 | 作り手のクレジット・匿名の集計（共有した回数・入口から来た人数） | — |

## 4. ユーザーに決めてもらうこと

1. YouTube のサムネイルを元にしない（写真か文字から作る）で良いか
2. 段階0（試作）から始めて良いか。試作の費用の上限（案：500円まで）
3. 写真から作るイラストの、1人あたりの回数（案：1か月に5枚まで、ベータ中は無料）
