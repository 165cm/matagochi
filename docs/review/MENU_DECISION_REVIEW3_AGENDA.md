## 0. お願いしたいこと

第2回では、4つのAIとも「選んだ料理に似た料理を出す（🔍 似た料理）」を推しました。
そのあと開発者から、次の感覚が出ました。

> 食べたいものを選ぶよりも、食べたくないものを消すほうがストレスが少ない気がする。消された料理の特徴をマイナスにして、方向を整えるのはどうか。

そこで、**消去法で寄せる形を一度作りました**（まだ本番には出していません）。
今回は、次の4つをお願いします。

1. 消去法の画面と仕様の **評価**（良い点・気になる点）
2. 第2回で出た心配（「選ばなかった＝嫌い」と決めつける・除きすぎて何も残らない）に、**この作り方で答えられているか**
3. 第2回の本命「🔍 似た料理」と **組み合わせるべきか**
4. 消した手がかりを **その場だけにするか、次の献立にも少し残すか**

前提と「守るもの」は前回と同じです（食べられない食材・器具・時間の条件はゆるめない／文字は最小限／1画面に目的は1つ／ボタンは高さ44px以上／AIの費用は月1,000円まで＝並べ方は端末の中の計算だけ／好みはスマホの中だけ／閲覧者も1タップ）。

## 2. 今回の仕様（消去法）

**画面**
- 写真4枚（16:9・2×2）。写真の上は ✓（左上）と ✕（右上・押せる大きさ44px）だけ。札（😋 好物・🆕 はじめて・🧺 買った材料を使う など）は写真の下の「⏱15分 · 😋 好物」の行に（サムネイルの文字とぶつけない）
- 気分の札は5つ：😋 いつもの／⚡ 15分以内／🥩 肉／🐟 魚／🍋 さっぱり（0品の札は出さない）
- 最初の4皿：好物を1枚（周期が来ている時）＋主役（肉・魚・卵豆腐・野菜）・食べ方の形（おかず・丼・麺）・味（和・洋・中）がなるべく重ならない3皿
- 「🔀 ほかの4皿」はやめた。代わりに、4枚とも違う時は「🙅 4皿とも消す」

**✕ で消すと**
- その枠だけ、新しい1皿に入れ替わる（ほかの3枚は残る＝比べる相手が消えない）
- 次の1皿は、今の点数の順を土台に **「消した料理と似ているほど後ろへ」**。似ているかは、同じ主役（鶏・豚・魚 など）1.5／主役の大きな種類（肉・魚など）2／食べ方の形 1.5／和洋中 1.5／こってり・ピリ辛・さっぱり・汁もの 1ずつ／時間の幅 0.5 を、消した料理ごとに足して決める
- **1品消しただけでは少し後ろへ。同じ特徴を2品・3品と消すほど、はっきり後ろへ**（「この魚料理は違う」と「魚は全部違う」を分けるため）
- あわせて、いま並んでいる料理と同じ種類も少し後ろへ（4枚を散らすため）

**手応えの見せ方**
- 消した料理に **2品以上で共通する特徴** を、上に「🙅 少なめに：🐟 魚 ✕　🍚 丼・ごはんもの ✕」と出す（3つまで）。札の ✕ を押すと、その特徴は数えない
- 「↩ 1つ戻す」で、最後に消した1皿を元の場所に戻せる
- 出せる料理がなくなったら「読み込み済みの候補はここまで（◯品）」

**残し方**
- 消した料理・少なめにした特徴は、**この画面を開いている間だけ**。ごはん方針・評価・次の献立には使っていない（ここを相談したい：5章の4）
- 見ただけ・閉じただけの料理は、今までどおり下げない

## 3. 第2回の心配への答え（作った側の考え）

| 第2回の心配 | 今回の作り |
|---|---|
| 「どれも違う」で4皿の種類を全部除くと、何も残らない（Codex・Gemini） | 除くのではなく「後ろへ回す」だけ。散らした4皿をまとめて消しても、どの特徴も1品ずつなので、方向は決めつけない |
| 「この魚料理は違う」と「魚は全部違う」は別（Codex） | 1品では少し、2品・3品と重なって初めてはっきり後ろへ。2品以上で共通した時だけ「少なめに」と見せる |
| 選んだ料理が消えて、比べる相手がなくなる（Gemini） | 消した1枠だけ入れ替える。残した3枚は動かない |
| ガチャで近づかない（開発者） | 消すたびに「少なめに」が育ち、4枚の顔ぶれがそれに沿って変わる |

## 4. まだ迷っていること

- 「消す」と「似た料理を見る（🔍）」の両方を置くと、ボタンが増える。どちらか1つにするか、両方置くか
- 写真の右上の ✕ が、サムネイルの右上の文字にかぶる
- 「🙅 4皿とも消す」は、第2回の「🔀 ほかの4皿」と同じくガチャに近くならないか
- 消した手がかりを次の献立にも残すと、自動の献立が当たるようになる一方、「たまたま今夜は魚の気分じゃなかった」が、ずっと魚を減らす原因になる

## 5. 評価してほしい点

1. 「✕ で消す → その枠だけ入れ替わる」は、選ぶより楽か？ 疲れた夜の人が迷わず使えるか？
2. 「似ているほど後ろへ」の点数の付け方（1品では少し・重なるほど強く）は妥当か？ 重みの直し方の案は？
3. 「🙅 少なめに：🐟 魚 ✕」の見せ方は、近づいている手応えになるか？ 文字が多くないか？
4. 消した手がかりは、**その場だけ／次の献立にも少し残す／何回もそろったら「ごはん方針」に提案する**、のどれがよいか？（残すなら、どれくらい・いつ消えるか）
5. 第2回の「🔍 似た料理」と組み合わせるべきか？ 組み合わせるなら、画面のどこに・どう置くか？

## 6. 回答のフォーマット（4つのAIで比べるため、これに合わせてください）

1. **評価**：良い点（3つまで）／気になる点（3つまで。直し方も）
2. **5章の5つの点への答え**（1つずつ短く）
3. **消去法をもっと良くする一番の案**：名前／ひとことで／画面の流れ（タップの順・スマホ縦1画面の見え方）／何を手がかりに次の1皿を選ぶか（端末の中の計算でできること）
4. **ほかの案（2個まで）**：名前／ひとことで／良い点／心配な点
5. **作る順番**：次に小さく試すこと → その次
6. **成功の測り方**：消去法が「近づいている」と数字でわかる見方
7. **他のAIに聞いてみたい問い**（1つ）
