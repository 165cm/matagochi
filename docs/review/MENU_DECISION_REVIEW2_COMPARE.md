# 献立決めUX 第2回ブレスト：4つのAIの比較（2026-11-07）

資料：`docs/review/MENU_DECISION_REVIEW2_AGENDA.md`／Claude の回答：`docs/review/MENU_DECISION_REVIEW2_CLAUDE.md`
Codex・Gemini・Grok の回答はユーザーがチャットに貼ったもの（要点を下にまとめた）。

## 1. 4つとも同じ意見

1. **開発者の心配は正しい**。「🔀 ほかの4皿」はガチャで、押しても近づかない
2. **本命は「選んだ料理に近い料理を出す」**（叩き台A）。近さは端末の中の点数（主役・味・タグ・時間・食べ方の形）でつくれる。AIの費用は0円
3. 近づけた結果は **その場だけ**。ごはん方針（ずっと残る好み）は変えない
4. **同じ料理名（親）は並べない**（近い料理＝別の料理）
5. **✓ をつけてから決める2タップは、ちょうどよい**
6. **気分の札8個は多い** → 4〜6個に
7. 献立カードの理由の札（🍂 旬の鮭 など）は役に立つ。残す
8. 最初の4皿に **好物を1枚** 入れる（Codex は「定番1＋有力2＋発見1」）

## 3. ほかのAIからの良い指摘（取り入れたい）

- **最初の4皿が4枚とも丼になる**（写真04）。主役と味だけでなく「おかず／丼・ごはんもの／麺」も散らす（Codex・Gemini）
- 「⚡ すぐできる」は **「⚡ 15分以内」** のほうが伝わる（Codex・Gemini）。「🍖 がっつり」は肉の札に見える（Gemini）
- 行き止まりの「条件に合う候補はここまで」は、スマホに届いた120品ほどしか見ていないので **「読み込み済みの候補はここまで」** が正確（Codex）
- 「近い料理」が少ない時は、似ていない料理を「似た料理」として **水増ししない**（2品でもよい）（Codex）
- 近づけるたびに条件を積み重ねない。**足場は1つだけ**（押した料理を新しい足場にする）（Codex）
- 何回か近づけたら、1枚は「少し違う料理」（行き止まりにしない）（Claude・Codex）
- 「変更」を開いた時点で、**元の料理は今夜の気分ではない**。最初の4皿は元の料理と少し違う方向に（Gemini）
- 料理名が1文字だけ2行目に落ちる（「ごは／ん」）。短い表示名か文字を少し小さく（Codex・Gemini）
- 「次の4皿」を押すたびに「⚡ 15分以内の4皿」「😋 好物の4皿」と切り口を変える（Gemini の案①）
- 成功の測り方：「近い料理」を出した直後に決まった割合が、最初の4皿と同じか高い（Gemini）。後半まで残る人はもともと決まりにくい人なので、今の形と新しい形で比べる（Codex）

## 4. Claude が考えを改めたこと

- **写真を押すだけで自動で近づける → ボタンで近づける**に変える（3つのAIが同じ意見）。✓ をつけただけでは何も変わらないほうが、わかりやすく、うっかり押しても怖くない
- **「🙅 どれも違う」はやめる**。散らした4皿の種類を全部除くと、出せる料理がほとんど残らない（Codex・Gemini の指摘どおり）
- 道のりは、**「🔍 ◯◯に近い ✕」の1行だけ**

## 5. まとめた案（たたき台）：「似た料理で寄せる」

1. **開いた時の4皿**：好物を1枚（周期が来ている料理がある時）＋散らした3皿。散らす時は、主役・味に加えて「おかず／丼・ごはんもの／麺」も分ける
2. **写真を押す** → ✓。下に2つのボタン：［🔍 似た料理］［✓ これにする］（どちらも高さ44px以上）。決める日なら、その上に「🛒 新しく買う：◯・◯」
3. **［🔍 似た料理］** → 押した料理は左上に✓のまま残り、ほかの3枚が「近い料理」に入れ替わる。上に1行「🔍 ◯◯に近い ✕」（✕ で最初の広い4皿へ）
4. 3枚のほうを押して［🔍 似た料理］を押せば、**それが新しい足場**（条件は積み重ねない）。2回目からは、3枚のうち1枚を「少し違う料理」にする。近い料理が少なければ、ある数だけ
5. 下の **「次の4皿」**（名前を変える）：足場がない時は今と同じ。最後は「読み込み済みの候補はここまで（◯品）」
6. **写真の上の札をやめ**、料理名の下の行に「⏱20分 · 😋 好物」と並べる（✓ だけ写真の上）
7. **気分の札を5個に**：😋 いつもの／⚡ 15分以内／🥩 肉／🐟 魚／🍋 さっぱり

近さの点数（端末の中だけ）：主役が同じ（鶏・豚・魚 など）+3／主役の大きな種類（肉・魚・卵豆腐・野菜）が同じ +2／和・洋・中が同じ +2／さっぱり・こってり・ピリ辛・汁ものが同じ +1ずつ／食べ方の形（おかず・丼・麺）が同じ +1／時間の差が10分以内 +1。近さが同じなら、今の点数（好み・周期・かぶらない）の高い順。

## 6. あとで確かめること

- 写真の大きさ（2×2 か、大きく1〜2枚か）は、**本物の YouTube のサムネイル**で比べる（作業した環境からは YouTube の画像を読み込めない。本番か、スマホでの確認で）
- 「次の4皿」の切り口めくり（Gemini 案①）は、「似た料理」の数字を見てから
