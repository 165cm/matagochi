## 1. 一番推したい案：「4枚くらべ」（見せて、寄せていく）

**ひとことで**：理由を聞かずに、大きな写真4枚を見せる。選ばなかった4枚から「今日の気分」を読み取って、次の4枚を寄せていく。

**画面の流れ（スマホ縦1画面・下からの大きなシート）**

```
┌──────────────────────┐
│ 11/8（土）  ✕        │ ← 見出しは日付だけ
│[🐟魚][🍖がっつり][🍋さっぱり][⏱すぐ][🍲あったか][😋いつもの][🆕はじめて] → 横にすべる
│┌────────┐┌────────┐│
││  写真   ││  写真   ││ ← 正方形の写真。小さな札だけ
││😋    ⏱15││🆕    ⏱20││   （😋好物・🆕はじめて・🧺使い回し・👧食べたい）
│└────────┘└────────┘│
│ 鶏の照り焼き  鮭のちゃんちゃん焼き │ ← 料理名（2行まで）
│┌────────┐┌────────┐│
││  写真   ││  写真   ││
│└────────┘└────────┘│
│ 麻婆豆腐      豚のしょうが焼き   │
│      [🔀 ほかの4品]         │ ← 大きなボタン1つ
└──────────────────────┘
```

1. 「⇄ 変更」を押す → シートが開き、写真4枚
2. 写真を押す → その日の料理になる（下の帯に「↩ 元に戻す」）。**ここまで2タップ**
3. 気に入るものがなければ「🔀 ほかの4品」 → 次の4枚
4. 気分がはっきりしている時は、上の札を1つ押す（もう一度押すと外す）

**並べ方のしくみ（AIは使わない・端末の中の計算だけ）**
- **最初の4枚は「散らす」**：今の点数（`Lifestyle.fit` / `propose` と同じ）の高い順から、主菜（肉・魚・卵豆腐・野菜）と味（和・洋・中）がなるべく重ならない4品。「4枚のうち1枚は当たる」を狙う
- **「🔀」は「この4枚は違う」という答え**：見せて選ばれなかった4品の特徴（主菜・味・主食・こってり/さっぱり・時間）を、この回だけ少し下げる。次の4枚は残りの中からまた散らす。2〜3回で自然に寄っていく（20の質問のような形）
- **選ばれた時**：選ばれた料理の特徴を少し上げ、並んでいたのに選ばれなかった3品は、ほんの少しだけ下げる（「G. 学習」の材料。上げ下げに上限と、日がたつと薄まる仕組み）
- 条件（食べられないもの・器具・時間）に合わない料理は、最初から入れない。確認が必要な自分のレシピは、4枚の下に小さく1行（「確認すると選べる 2品 ›」）

**なぜストレスが減り、満足が上がるか**
- 文字を読まず、写真で「食べたい」がわかる。疲れた夜でも「見て押す」だけ
- 4つは比べやすい数（多すぎて迷わない）。でも「🔀」を押すたびに別の4品が出るので、400品の幅に出会える
- 「なぜ違うか」を答えなくていい。押さなかったこと自体が答えになる
- 最後に押すのは自分なので「選ばされた」ではなく「自分で選んだ」感が残る

## 2. ほかの案

### ② 今日のカードで「🎲 もう一皿」（その場で差し替え）
- **ひとことで**：今日の「今夜のおすすめ」の写真の下に「🎲」。押すとシートを開かず、カードの料理がその場で次の1品に変わる
- **効くお題**：A・E・C
- **良い点**：いちばん少ない手数。「なんか違う」の夜に、くじを引く気軽さ。差し替えた回数＝「違う」の答えとして①と同じ学習に使える
- **心配な点**：何回も押すと、戻りたくなる（「↩ ひとつ前」が必要）。比べられないので、迷う人には①のほうが合う

### ③ 献立まるごと「組み直し」（数日分を1画面で）
- **ひとことで**：献立の数日分を写真の列で並べ、決めた日に📌。「🔀 📌以外を組み直す」で、かぶらない・使い回しを守ったまま残りを一度に入れ替える。日の写真を長押しで動かして入れ替え
- **効くお題**：D・H
- **良い点**：買い物の前に「まとめて決める」場面がとても速くなる。1日ずつ開かなくていい。今の自動の決め方（`propose`）をそのまま使える
- **心配な点**：長押しで動かすのは、ITが苦手な人には見つけにくい（「⋯」の入れ替えも残す）

### ④ 家族の「食べたいストック」
- **ひとことで**：見るだけの家族に、週1回「今週、食べたいのは？」の写真10枚（👍／パスの2択・スワイプでもボタンでも）。👍は決める人の画面で写真に「👧」の札として出て、点数も上がる
- **効くお題**：F・G
- **良い点**：決める人の手間は増えない。家族は1分で終わる。リクエストを「言葉で送る」より気軽
- **心配な点**：家族が答えない週もある（答えなくても困らない作りに）。👍が多すぎると、かぶらない決まりとぶつかる（点数の上げ幅を、リクエストの +80 より小さくする）

### ⑤ 理由は「文字」から「写真の札」へ
- **ひとことで**：理由の文章をやめ、写真の角の小さな札（😋好物・🆕はじめて・🧺使い回し・🍂旬・👧食べたい・📌いつもの曜日）にする。意味はⓘで1回だけ説明
- **効くお題**：E・H
- **良い点**：理由が見えるので「これでいい」と言いやすい。文字は増えない。①〜④すべてで同じ札を使える
- **心配な点**：札が増えすぎると逆にうるさい（1枚に1つまで）

### ⑥ 400品を「届ける」仕組みの見直し（画面の裏側）
- **ひとことで**：今は新着のうち120品だけを端末に送っている。全部の料理の「目次」（id・料理名・親・時間・タグ・写真のアドレスだけ。約400品で数十KB）を送り、詳しい材料・手順は選んだ時に読み込む
- **効くお題**：B
- **良い点**：AIの費用はかからない。「🔀」を何回押しても、本当に400品から出せる
- **心配な点**：通信量が少し増える。古い版のアプリも使うので、今のAPIの形は残して、新しい形を足す

## 3. やめる・減らすべきもの

- **「変えたい理由は？」の3択**：「🔀」と札で、聞かずにわかるようにする（「時間」「材料」は札の「⏱すぐ」で代わりになる）
- **変更の画面の「🔗 動画のURL」欄**：レシピタブの「＋」と「⋯」の中へ。毎回は使わない
- **「🆕 まだ作っていない」「⭐ 評価順ベスト3」「ほかの候補」の見出しと、各行の説明1行**：写真の札に置きかえる
- **「ほかの候補を見る（最大12品）」の上限**：「🔀」で何回でも
- （残すもの）買った材料がある時の「🧺 買った◯◯は？」は、大事な1問なので残す。ただし答えは札（🧺）で見せ、4枚の並べ方に入れる

## 4. 成功の測り方（名前・料理名は送らず、回数だけ）

| 数字 | 今 → めざす |
|---|---|
| 自動の提案をそのまま採用した割合 | 上がる（⑤の札で） |
| 変更を開いて、決めて閉じた割合 | 7割以上 |
| 変更を開いてから決めるまで | 「🔀」0〜1回で決まる人が7割以上・15秒以内 |
| 4枚のどの位置が選ばれたか | 左上ばかりなら、散らし方が弱い（並べ方の見直し） |
| 変更で選んだ料理の「また食べたい（明日でも・毎週）」の割合 | 自動の提案と同じか、それ以上 |
| 4週間で一度でも画面に出た料理の数 | 400品のうちの割合が上がる（幅が生きている） |

## 5. 作る順番

1. **最初の一歩（小さく試す）**：今の変更の画面を「写真4枚＋🔀」に置きかえるだけ。並べ方は今の点数に「散らす」を足すだけ。理由の質問・URL欄・見出しを外す。数字をとる（開いた・🔀・選んだ・位置）
2. **次**：🔀の「この回だけ下げる」と、気分の札を足す。⑤の写真の札を、献立と今日のカードにも
3. **その次**：⑥ 全部の料理の目次を届ける。選んだ・選ばなかったの学習を長く残す（端末の中に、新しい項目として足す）
4. **最後**：② 今日の「🎲」・③ 数日分の組み直し・④ 家族の食べたいストック

## 6. リスクと「守るもの」の確認

- **食べられない食材・器具・時間**：4枚にも🔀にも、条件に合う料理しか入れない → ぶつからない
- **品数の水増し**：条件に合う料理が4品ない時は、ある数だけ出し「合う料理は◯品です」と正直に → ぶつからない
- **写真の質**：YouTube のサムネイルは大きな文字入りが多く、正方形に切ると食欲に訴えにくいものがある。写真の切り方（中央・少し上）は試して確かめる必要がある（いちばんの心配）
- **閲覧者**：同じ4枚。押すと「🙋 これがいい」を送る（1タップ）→ ぶつからない
- **文字の量**：今より減る。札の意味はⓘで1回だけ
- **AIの費用**：並べ方・学習とも端末の中の計算だけ。0円 → ぶつからない
- **好みの方針の扱い**：学習は端末の中だけ。家族の同期にもAIにも送らない → ぶつからない
- **データの形**：今の項目は変えず、学習用の項目を足すだけ。APIは新しい形を足す → ぶつからない
- **学びすぎ**：1回の「🔀」で大きく寄せると、魚が一度出なくなるとずっと出ない。上げ下げに上限と、日がたつと薄まる仕組みが必要
