## 2. いまの仕様（要点）

- **写真**：YouTube のサムネイルと同じ **16:9**（見切れない。4:3 の画像の上下の黒い帯は切り落とす）。2×2 で、1枚は横幅 約175px（高さ 約98px）。写真の下に料理名（2行まで）と⏱時間
- **写真の札**（左上に1つ）：🙋 リクエスト／🧺 買った材料を使う／😋 好物／🆕 はじめて。4枚とも同じ札なら出さない
- **気分の札**（1列・横にすべる・1つだけ・任意）：🐟 魚／🍖 がっつり／🍋 さっぱり／⚡ すぐできる（15分以内）／🍲 あったか／🌶 ピリ辛／😋 いつもの／🆕 はじめて。0品の札は出さない。ごはん方針は変えない（その場だけ）
- **材料を買ったあと**：「🧺 買った◯◯を使う」の札がはじめからON（質問はしない）
- **最初の4皿**：条件に合う料理を点数の高い順に並べ、肉・魚・卵豆腐・野菜や和・洋・中が **なるべく重ならない** ように選ぶ。同じ料理名（親）は1枚だけ
- **🔀 ほかの4皿**：**まだ見ていない料理から、同じ決まりで次の4皿**。前の4皿へ戻れる。最後の組では「条件に合う候補はここまで（◯品）」と出す
- **選ぶ**：写真を押して✓ →「✓ 『◯◯』にする」。献立を決めた日は「🛒 新しく買う：◯・◯」も出す
- **学び方**：好みとして学ぶのは「選んだ・作った・評価した」だけ。見せたのに選ばなかった料理は下げない
- **候補の数**：スマホに届いているのは、新着レシピのうち最大120品＋みんなの定番20品＋最初から入っている48品＋自分のレシピ（サーバーには約400品）

## 3. 開発者の心配（今回いちばん聞きたいこと）

> 4枚の写真が出たあと「ほかの4皿」を押す流れだと、結局ガチャで、食べたいレシピにたどり着く精度が上がらない。少しでも前に進んで、食べたいものに近づいている体感がないと、苦痛になってしまうのではないか。

いまの「🔀」は、**押した人が何を思ったかを受け取っていません**（選ばなかった料理を下げない、と決めたため）。なので2回目の4皿は「点数の次の順位」から選ぶだけで、1回目より当たりやすくなるわけではありません。気分の札を押せば近づきますが、押すかどうかは本人まかせです。

**問い：選ぶ人に余計な手間・文字を増やさずに、1回押すごとに「近づいている」と感じられる仕組みはどう作るか？**

## 4. 叩き台（Claude の仮案。これにとらわれなくてよい）

- **A. 「この感じで」**：4枚のどれかを押すと、✓ と一緒に「この感じでもっと」が出る。押すと、その料理に **近い** 4皿（主役・味・時間・タグが近く、料理名は別）が出る。広い4皿 → 近い4皿 → もっと近い4皿、と寄っていく
- **B. 「どれも違う」**：「🔀」を「🙅 どれも違う」に変える。押すと、いま見せた4皿の **主役と味を除いて** 次の4皿を出す。除いたものは上に小さく「肉・中華 以外」と見せ、押すと戻せる（何が絞れたかが目に見える）
- **C. 道のりを見せる**：上に、選んできた方向を小さく並べる（例「🐟 魚 › さっぱり › 鮭のホイル焼きに近い」）。押すとそこまで戻れる
- 心配：A・B は「1回の答えで大きく寄せすぎる」と、ほかの料理に出会えなくなる。B は「選ばなかった＝嫌い」と決めつけない作りが必要（その場だけ・好みとしては残さない）
