# 献立決めUX 第3回の相談：Claude の回答（2026-11-07）

資料：`docs/review/MENU_DECISION_REVIEW3_AGENDA.md`・画面の写真 `docs/review/menu-4dishes/`（作った本人の回答なので、気になる点を多めに書く）

## 1. 評価

**良い点**
1. 「これは違う」は見た瞬間にわかるので、「食べたいもの」を考えるより頭を使わない。疲れた夜に合う
2. 消した1枠だけ入れ替わるので、気になる料理は残ったまま。「さっきのほうが良かった」が起きにくい
3. 2品以上で重なった時だけ「🙅 少なめに：🐟 魚」と出るので、1回の ✕ で決めつけない

**気になる点（直し方）**
1. **1品目を消した時の手応えが弱い**。「🙅 1品消しました」は文字だけで、何が変わったかわからない → 消した料理を小さな写真のまま上の1列に残す（「消したお皿」の列。押すと戻る）。文字なしで「これだけ絞った」が見える（3章）
2. **✕ が写真の右上で、サムネイルの文字にかぶる** → ✕ を写真の外、料理名の行の右はしへ（押せる大きさ44pxのまま）。写真の上は ✓ だけにする
3. **「🙅 4皿とも消す」はガチャに近い** → 残すが、まとめて消した4品は1品あたりの重みを半分にする（よく見ずに消しているので）。ボタンは文字を小さく、目立たせない

## 2. 5章の5つの点への答え

1. **選ぶより楽**。迷っている時は「これじゃない」から始めるほうが自然。ただし ✕ が写真の上だと、写真を押して決める操作とまぎれる → ✕ は写真の外に
2. **点数の付け方は妥当**。足したいのは2つ：①同じ料理名（親）を消したら、その料理名の作り方はその場では出さない（いちばん強い「違う」）②1つの特徴が後ろへ回る強さに上限（同じ特徴を3品消したら、それ以上は強くしない）。消し続けても、ほかの特徴の料理まで出なくならないように
3. **手応えになる**。ただし2品目まで出ないので、1品目は「消したお皿」の列で見せる。文字は「🙅 少なめに：」の5文字＋札だけで多くない
4. **並べ方に使うのは、その場だけ**。ただし回数は数えておき、**ちがう日に3回以上、同じ特徴を「少なめに」まで消した**時だけ、今ある「記録からの提案」（§43）で「魚の料理を少なめにしますか？」と1回聞く。本人が「はい」と答えた時だけ、ごはん方針に入る。勝手に残さない（「たまたま今夜は魚の気分じゃない」を守る）
5. **組み合わせる。ただし主役は消去法**。✓ をつけた時の下の帯に、小さく「🔍 似た料理」を1つだけ（「これに近いけど、ちょっと違う」人のため）。押すと、✓ をつけた料理を残して、残り3枚を似た料理に入れ替える

## 3. 消去法をもっと良くする一番の案：「消したお皿の列」

**ひとことで**：消した料理を、上に小さな写真で並べて残す。文字を読まなくても「何を消して、どこまで絞れたか」が見え、押せば戻せる。

**画面の流れ（スマホ縦1画面）**

```
┌─────────────────────┐
│ 11/8（日）                       ✕ │
│[😋いつもの][⚡15分以内][🥩肉][🐟魚]…    │
│ 消した：[小][小][小]  🙅 少なめに：🐟 魚 ✕ │ ← 1行。小さな写真（32px）を3枚まで＋「ほか◯」
│ ┌──────┐ ┌──────┐          │
│ │ 写真 16:9 │ │ 写真 16:9 │          │
│ └──────┘ └──────┘          │
│ 料理名        ✕  料理名        ✕   │ ← ✕ は写真の外
│ ⏱15分 · 😋 好物    ⏱20分            │
│ （2段目も同じ）                       │
│      🙅 4皿とも消す（小さく）           │
│ ［✓「◯◯」にする］［🔍 似た料理］        │ ← ✓ をつけた時だけ
└─────────────────────┘
```

1. ✕ を押す → その枠が入れ替わり、消した料理は上の「消した：」の列に小さな写真で入る
2. 同じ特徴が2品重なると、列の右に「🙅 少なめに：🐟 魚 ✕」
3. 列の小さな写真を押すと、その料理が戻る（「↩ 1つ戻す」はこれで代わる。どれでも戻せる）
4. 写真を押して ✓ →「✓『◯◯』にする」で決める。近いけど少し違う時は「🔍 似た料理」

**次の1皿の選び方（端末の中の計算だけ）**
- 今の作り方のまま（今の点数の順を土台に、消した料理と似ているほど後ろへ・並んでいる料理と同じ種類も少し後ろへ）
- 足すこと：同じ料理名を消したら、その場ではその料理名を出さない／1つの特徴の強さは3品分まで／「4皿とも消す」は1品あたり半分の重み

## 4. ほかの案

| 案 | ひとことで | 良い点 | 心配な点 |
|---|---|---|---|
| 消しながら「残した」も使う | 2回以上入れ替わっても残っている料理は、「消さなかった」ことを小さなプラスにする（その場だけ） | 消すだけで、好きな方向にも少し寄る | 残ったのは「まあいい」程度かもしれない。プラスはごく小さく |
| 献立の数日分にも ✕ | 献立タブで、気に入らない日の写真の ✕ を押すと、その日だけ消去法で入れ替わる（画面を開かずに） | 「まとめて決める」時が速くなる | 献立カードに ✕ が増えて、うっかり押す心配。「↩ 元に戻す」の帯が必要 |

## 5. 作る順番

1. **次に小さく試すこと**：✕ を写真の外へ／「消したお皿」の列（押すと戻る）／同じ料理名を消したら出さない・特徴の強さに上限・「4皿とも消す」は半分の重み
2. **その次**：✓ の帯に「🔍 似た料理」／ちがう日に3回そろったら、記録からの提案で1回だけ聞く／400品の軽い目次（消せる候補が多いほど、寄せる精度が上がる）

## 6. 成功の測り方（回数だけ・名前や料理名は送らない）

- **消した数ごとの、決まった割合**：0品・1〜2品・3〜4品・5品以上。**3品以内で決まる人が7割以上**なら「近づいている」
- **「少なめに」が出たあと、決まるまでの消す数**：出る前より少ない（寄せが効いている）
- **戻した割合・「少なめに」の ✕ を押した割合**：多すぎれば、寄せ方が強すぎる・読み違えている
- **決めずに閉じた割合**：「🔀 ほかの4皿」の時より下がる
- **「4皿とも消す」の回数**：多ければ、最初の4皿の選び方が外れている
