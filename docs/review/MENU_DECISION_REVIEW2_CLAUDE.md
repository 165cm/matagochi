## 1. 今の画面の評価

**良い点**
1. 写真が主役になり、文字は料理名と時間だけ。前の一覧より「見て選ぶ」になった
2. 16:9 で見切れないので、YouTube のサムネイル（料理の全体・盛り付け）がそのまま伝わる
3. 「✓ → ◯◯にする」の下の帯で、決める前に「新しく買う物」が見える。買い物の後悔が減る

**気になる点**
1. **「🔀 ほかの4皿」はガチャ**（開発者の心配のとおり）。押した人の気持ちを受け取らないので、何回押しても近づかない → 3章の案で直す
2. **写真の上の札が、サムネイルの文字にかぶる**。YouTube のサムネイルは左上・右上に大きな文字が多い → 札は写真の外（料理名の下の「⏱15分 · 😋好物」の行）に出す。✓ だけは写真の右上に残す
3. **気分の札が8個で、1画面に3つ半しか見えない**。横にすべると気づかない人が多い → 5個に減らす（5章の3）

## 2. 5章の5つの点への答え

1. **2×2（約175×98px）でよい**。縦1列で大きく（06）は、1画面に2枚しか見えず比べられない。175px あれば料理かどうか・好みかどうかは見分けられる。ただし、まわりの余白を少し削って横幅を広げる（画面の左右16px→12px、写真の間10px→8px）
2. 献立カードの理由の札は **役に立つ**（「なぜこれ？」がわかると、変えずに済む）。今夜の4皿の札は、写真の外へ（1の2）
3. **8個は多い**。5個に：🐟 魚／🍖 がっつり／🍋 さっぱり／⚡ すぐできる／😋 いつもの。ピリ辛・あったか・はじめては外す（あったかは冬だけ出す、でもよい）
4. **2タップはちょうどよい**。ただし3章の案では「1回目のタップ＝近づける」になるので、決めるのは下の帯のボタン（これまでと同じ2タップ）
5. 名前は「🔀 ほかの4皿」→ **「🙅 どれも違う」** に変え、押した結果を目に見せる（3章）。行き止まりの「条件に合う候補はここまで（◯品）」は正直でよい

## 3. 「近づく体感」の一番推したい案：「キープして、寄せていく」

**ひとことで**：押した1枚を左上にキープしたまま、残りの3枚がその料理に近いものへ入れ替わる。押すたびに、キープより良さそうな料理が近くに集まってくる。

**画面の流れ（スマホ縦1画面）**

```
① 開いた時（今と同じ・種類を散らした4皿）
┌───────────────┐
│ 11/8（日）                   ✕ │
│[🐟魚][🍖がっつり][🍋さっぱり][⚡すぐ][😋いつもの]│
│ [ 鮭のホイル焼き ][ 豚キムチ   ]│
│ [ 豆腐ステーキ  ][ ナポリタン ]│
│        [🙅 どれも違う]          │
└───────────────┘

② 「鮭のホイル焼き」を押す
  → 左上にキープ（✓・赤い枠）。残りの3枚が「鮭に近い」料理に入れ替わる
    （例：さばのみそ煮・鮭のちゃんちゃん焼き・たらの野菜あんかけ）
  → 上の札のうち、その料理に当てはまるもの（🐟魚・🍋さっぱり）が自動で点く
    ＝「いま、魚・さっぱりに寄せています」が言葉なしで見える
  → 下に「✓『鮭のホイル焼き』にする」

③ 「たらの野菜あんかけ」のほうが良ければ、それを押す
  → キープが入れ替わり、残り3枚が「たら」に近いものへ
  → 決めたい時は下の帯を押す（今と同じ2タップ）

④ 4枚ともピンとこない時は「🙅 どれも違う」
  → いま見せた4枚の主役と味（例：肉・中華）を除いた4皿に
  → 上に小さく「肉・中華 以外 ✕」と出る（✕ で戻せる）。何が絞れたかが見える
```

**なぜ近づくと感じるか**
- 押すたびに「今のいちばん」が残り、まわりが似たものに変わる。眼科の検査（「1と2、どちらが見えますか？」）と同じで、比べるたびに良くなる。**後戻りしない**ので、ガチャのように「さっきのほうが良かった」が起きない
- 札が自動で点くので、「魚・さっぱりに寄ってきた」が目に見える
- 「どれも違う」も、除いたものが見えるので「絞れた」と感じる

**次の4皿の選び方（端末の中の計算だけ・AIは使わない）**
- キープした料理と、まだ見ていない各料理の「近さ」を点数にする：主役（鶏・豚・牛・ひき肉・魚・卵・豆腐・野菜）が同じ +3／主役の大きな種類（肉・魚・卵豆腐・野菜）が同じ +2／味の系統（和・洋・中）が同じ +2／さっぱり・こってり・ピリ辛・汁ものが同じ +1ずつ／主食（ごはん・麺・パン）が同じ +1／時間が近い（差が10分以内）+1
- 「近さ」が高い順に、今の点数（好み・周期・かぶらない）も足して並べ、**料理名（親）がかぶらないように**3皿。3皿の中で主食はなるべく分ける（全部丼にしない）
- 「どれも違う」は、その場だけ除く。好みとしては残さない（Codex の「見送り＝嫌いと決めつけない」を守る）
- 寄せすぎ対策：キープを3回入れ替えても決まらない時は、3枚のうち1枚を「少し離れた料理」にする（行き止まりにしない）

## 4. ほかの案

| 案 | ひとことで | 良い点 | 心配な点 |
|---|---|---|---|
| ① 最初の4皿に「いつもの」を1枚 | 開いた時の4皿の1枚を、好物（評価が「毎週」以上で、周期が来ている料理）にする。残り3枚は散らす | 疲れた夜の「安全な1枚」。決まる割合が上がる | 好物がまだない人には効かない（その時は4枚とも散らす） |
| ② 元の料理を「ずらす」 | 材料を買った料理を変える時、下の帯に「元の料理は明日にずらす」を出す（今ある「ずらす」の仕組みを使う） | 食材をムダにせず、「使わされている感」もない | 明日が決まっている時は、明日の料理がさらにずれる（今の仕組みと同じ扱い） |
| ③ 「食べたい」をためる | 決めなかった時も、キープした料理を「🙋 また今度」として残し、次の献立の点数を少し上げる | 「選びかけた」も無駄にならない | 上げすぎると同じ料理が出続ける（上限をつける） |

## 5. 叩き台（A・B・C）への意見

- **A「この感じで」**：使う。ただし「この感じでもっと」のボタンを足さず、**写真を押す＝キープ＋近づける**にまとめる（3章）。ボタンが増えない
- **B「どれも違う」**：使う。除いたものを札で見せ、✕ で戻せるようにする
- **C「道のり」**：言葉の道のり（「🐟 › さっぱり › …」）は文字が増えるので使わない。代わりに **上の気分の札が自動で点く** ことで見せる

## 6. 前回の問いへの答え

- **Codex（見送りを嫌いと誤解しない手がかり）**：いちばん強い手がかりは「押した1枚」。次に「どれも違う」（その場だけ）。見ただけ・閉じただけは使わない
- **Codex（買い足しと食べたいがぶつかる時）**：食べたいほうを先に出し、下の帯で「🛒 新しく買う 2品」と差を見せるだけ。選ぶのは本人。数日分の組み直しの時だけ、同じくらいの点数なら買い足しが少ないほうを先に
- **Gemini（大きく2〜3品か、一覧6〜8品か）**：その間の4品。2〜3品では比べる相手が足りず、6〜8品では16:9の写真が小さすぎてサムネイルの文字が読めない
- **Gemini（買ったあとに、使わされている感なく）**：①「🧺 買った◯◯を使う」をはじめからON（今の形）、②「元の料理は明日にずらす」（4章の②）。「使い切りましょう」のような押しつけの言葉は使わない
- **Grok（気分の札の数と言葉・3パターン）**：
  - 素材5つ：🍖 肉／🐟 魚／🥚 卵・豆腐／🥬 野菜／🍜 麺
  - 気分5つ：🍖 がっつり／🍋 さっぱり／🍲 あったか／🌶 ピリ辛／⚡ すぐできる
  - 混ぜて5つ（おすすめ）：🐟 魚／🍖 がっつり／🍋 さっぱり／⚡ すぐできる／😋 いつもの
- **Grok（まとめて決める時の入れ替え）**：残したい日に📌 →「📌以外を組み直す」。日を入れ替えたい時は、2つの日を順に押すと入れ替わる（長押しで動かす操作は使わない）
- **Claude（自分の問い）への今の考え**：開いた時の4皿は「好物1枚＋散らす3枚」（4章の①）。文字入りのサムネイルは、写真に札を重ねない（1章の2）ことで、文字を「情報」として生かす

## 8. 成功の測り方（回数だけ・名前や料理名は送らない）

- **キープを入れ替えた回数ごとに、決まった割合**：0回（最初の4皿で決まる）・1回・2回…。2回以内で決まる人が7割以上なら「近づいている」
- **「どれも違う」を押した回数**：今の「🔀」より少なくなる
- **決めずに閉じた割合**：下がる
- **最初にキープした料理と、最後に決めた料理の近さ**：近ければ「寄せる」が効いている（遠ければ、寄せ方の点数を見直す）
