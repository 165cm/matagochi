# 画面のルール（UI_RULES）

画面を作る・直す時は、これを守る。昔の方針は `docs/DESIGN_DIRECTION.md`、機能ごとの細かい仕様は `docs/APP_MAP.md`。

## 1. 文字は最小限（いちばん大事）

- **伝えるべきことは伝え、くり返しと毎回の説明は削る**。見出しと本文、ボタンと説明で同じことを2度書かない
- 毎回読まなくていい説明は **ⓘ**（`tip("…")`：押すと吹き出し）に入れる
- 意味が伝わるところは**絵文字＋短い言葉**（例：🗓 毎日の献立／🎟 30枚／⏰3分／🧂 常備品）
- 1枚のカードを使うほどでない情報は、1行（チップ・ボタン＋ひとこと）にまとめる
- 理由・状態の行は1行で切れない長さに（献立カードの理由は約12文字：「ふたりの好物・8日ぶり」「昨日は魚 → 肉」）
- 押した結果は、押した場所の近くか、画面の下の小さな帯で返す（トーストだけに頼らない）。取り消せる操作は「↩ 元に戻す」を付ける

## 1-2. はじめての人でも迷わず押せる言葉（基本方針。2026-10-04 のユーザーの判断）

IT が苦手な人が、ためらわずに押せる・読める言葉にする。新しい画面・ボタン・知らせを作る時は、これを先に確かめる。

- **専門の言葉を使わない**。言いかえの例：版・バージョン → 「新しくなりました」「最新情報」／更新する → 「最新情報に更新する」（何をどうするかを付ける。「更新」だけにしない）／同期 → 「家族と同じにする」／読み込み直す・再読み込み → 「開き直す」／キャッシュ・サーバー・エラー・通信 → 使わない（「つながりません」「少し待ってからもう一度」）／ログイン → 「入る」も可（画面の決まった言葉に合わせる）／AI の解析 → 「AI が読みます」
- **ボタンは、押すと何が起きるかを動詞で**（「最新情報に更新する」「献立に入れる」「保存する」）。「OK」「はい」「更新」「実行」だけにしない
- **不安を先に消す一言を添える**：押しても消えない（「献立や記録はそのまま残ります」）・お金がかからない（「無料」「チケットは使いません」）・あとで戻せる（「↩ 元に戻す」）。必要な時だけ1行で
- **押さなくても困らない時は、そう書く**（「あとででも大丈夫」）。急がせる言葉・脅す言葉（「今すぐ」「失われます」）は使わない
- **うまくいかなかった時は、何が起きたか＋次にすること**を、責めない言葉で（「つながりませんでした。少し待ってからもう一度押してください」）。エラーの番号や英語は出さない
- 例：新しい版の知らせ ×「新しい版があります［更新する］」→ ○「✨ 新しくなりました／献立や記録はそのまま残ります［最新情報に更新する］」（ボタンの言葉は 2026-10-04 のユーザーの判断）

## 2. スマホ1画面の密度

- スマホが基本（縦 390×844 で確認）。横持ち・パソコンでも崩れないこと
- 主な操作のボタンは押せる大きさ（高さ44px以上）。画面からはみ出さない
- 1画面に主な目的は1つ

## 3. 余白とキャラクター「よはく」

よはくは**画面の余白にこっそり住んでいる**。コンテンツの中心には置かない。

| 決まり | 値 |
|---|---|
| 1画面に出すよはく | 1匹（多くても2匹、120px以上離す） |
| よはくとUIの間 | 24px以上（文字12px・ボタン16px・料理写真16px以上） |
| 画面の端から | 12px以上（顔は20px以上） |
| のぞく時 | 体の30〜45%を隠し、顔は70%以上見せる |
| 大きさ | 空っぽの画面 96px、カードの中 52〜64px、料理モードの案内 88px |
| **高さを取らない** | よはくのためだけの行を足さない（すきまを作らない）。既にある余白・線・カードの端に乗せる |

- 画像は `assets/yohaku/*.webp`（512×512・透明・体は70〜80%）。出すのは `yohaku(pose, cls)`（`daily-ui.js`）
- 動き（ゆれる・手をふる・ひょっこり）は `prefers-reduced-motion` で止める
- どこにどのポーズを出しているかは `docs/APP_MAP.md` §34

## 4. 色・形

- 温かいアイボリーの背景、トマトのオレンジ（`--tomato`）が主な色、丸みのあるカード
- 料理名と写真を強く、説明は控えめに
- 色だけに頼らず、文字や記号でも区別する（✓／△／✗ など）

## 5. 料理中の画面

- 料理中は手がふさがっている：大きな「次へ」、横スワイプ、✋手の形、⏰タイマー
- 動画はその手順の場面をくり返す（ボタンは置かない）。「✕ 終わる」ははっきり見える所に
- タイマーは左上に小さな札で並べる（「2:59 3 炒める ✕」）
