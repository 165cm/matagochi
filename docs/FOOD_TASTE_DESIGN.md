# 食の好み診断 / 2026-09-23

## 体験

初回設定5ページ目を、静止画8枚の左右スワイプに変更。「今は違う」「食べたい」「わからない」。ボタン・左右キーでも操作可能。回答は端末内に逐次保存し、戻す・やり直す・未回答で次へ進むことができる。バックアップには含み、家族同期には含めない。

料理コンテンツの切り口を、満足感（ごほうびガッツリ）、家庭的なやさしい味（ご自愛ほっこり）、彩りと洋風（おうちカフェ）、香りとうまみ（香りを楽しむ）の4種類に編集分類。実在のインフルエンサーとの提携・推薦・同一性を示すものではない。ユーザーの指定により人物名は表示しない。

8皿を交互のジャンル順で提示。4皿以上に好き/今は違うを回答し、好きが2皿以上の場合のみ最多カテゴリを表示。同点は「おいしいもの探検系」、不足時は「まだまだ探索中」。医学的・心理学的診断、栄養評価ではなく、その時点の写真選択に基づく好みの傾向。比率や他者との比較値は表示しない。

食べたいと選んだ料理と同じ料理名、および和風/洋風/中華風の属性を献立の加点に使用。食べられない食材・器具・調理時間の制約を優先。左への回答は食材の禁止に変換しない。全て未回答の場合は従来の好み設定を保持。

明示的な共有ボタンで結果のPNG画像を作成。対応端末は共有シート、それ以外は画像ダウンロード。画像には診断タイプ・アプリURLのみを載せ、食材制限・回答履歴・所持品は載せない。SNSへの自動投稿はしない。共有URL `?quiz=1` は診断画面を直接開き、終了後に元の設定画面へ戻る。未回答の初回設定を完了扱いにせず、既存の回答も消さない。拡散や課金率への効果は未検証で、保証しない。

## 調味料の初期値

以下の公開調査で80%以上という水準が確認できる、塩・しょうゆ・こしょう・砂糖・みそ・マヨネーズ・ケチャップ・めんつゆ・酢を初期「ある」にする。該当カテゴリを開いた時点で未設定の項目だけを補い、明示した「ない」「未確認」やカスタム項目は上書きしない。その他は未確認。画面で訂正可能。

- [MyVoice 調味料に関する調査（第8回）](https://prtimes.jp/main/html/rd/p/000001572.000007815.html): 2024年12月のインターネット調査、9,254人。塩・しょうゆ・こしょうは9割台、砂糖・味噌・マヨネーズは8割台後半、ケチャップ・めんつゆは8割台前半。「ソース」は種類が特定されていないため中濃ソースに転用しない。
- [Nadia 調味料調査](https://nadia-corp.co.jp/news/news-release/2026_05_29-2/): 2026年2月27日〜3月5日、Nadia登録者1,183人（設問によって異なる）。常備・継続購入の酢は85.1%。同調査でもしょうゆ・塩・砂糖・味噌・マヨネーズは80%以上。

標本・質問が異なるため数値を合算しない。一人暮らし・二人暮らしに限定した代表値ではなく、入力を減らすための編集上の初期値。全ユーザーの実際の所持を断定するものではない。
